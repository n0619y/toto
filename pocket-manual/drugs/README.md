# 薬剤DB(用量の正本)

**本マニュアルの薬物用量の「正本」はこの DB**(`薬剤DB.csv`)とする。
疾患ページには薬剤の役割と要点のみを書き、用量・最大量・注意はここに集約する。
**添付文書が改訂されたら、この DB の該当行を1箇所直せば全疾患ページに反映される**運用。

## Notion への取り込み方(データベースとしてインポート)

1. Notion で `Import` → `Markdown & CSV` を選び `薬剤DB.csv` を選択
2. CSV はデータベース(テーブル)として取り込まれ、**1行が1薬剤ページ**になる
3. インポート後の設定:
   - 「ステータス」列をセレクト型に変更(要校閲 / 校閲中 / 承認済み / 要改訂)
   - 「関連疾患ページ」列をリレーション型に変更し、疾患一覧データベースと連結
4. 再インポートすると別データベースができるため、**運用開始後の更新は Notion 上で直接行い、GitHub 側の CSV にも同じ変更を反映**する(正本の二重管理を防ぐため、変更時は必ず両方更新)

## 列定義

| 列 | 内容 |
|---|---|
| 薬剤名(商品名)/ 一般名 / 分類 | 添付文書の名称に合わせる |
| 本マニュアル内の用途 | どの疾患の何に使うか(第一選択/第二選択など) |
| 小児用量 / 最大量 / 投与経路 | **添付文書記載を優先**。ガイドライン用量と乖離がある場合は両方併記 |
| 小児適応 | 添付文書に小児の用法・用量記載があるか |
| 適応外使用 | ⚠️フラグ。適応外の場合はその旨と根拠ガイドラインを明記 |
| 主な注意・禁忌 | 禁忌・慎重投与・モニタリングの要点 |
| 出典 | 添付文書(版)・ガイドライン名 |
| ステータス / 最終確認日 | 校閲フローに従う。添付文書改訂を確認した日付 |
| 関連疾患ページ | この薬剤を参照している疾患ページ |

## ルール

- 新しい疾患ページを書くとき、登場する薬剤は必ずこの DB に行を追加する(疾患ページに用量を直書きしない)
- 【要校閲】が残る行はステータス「要校閲」のまま。原典照合後に「承認済み」へ
- 年1回、全行の添付文書改訂有無を確認し「最終確認日」を更新する
