# 小児循環器ポケットマニュアル 要件定義書

- 版: v0.1(ドラフト)
- 作成日: 2026-08-04
- ステータス: 医師レビュー待ち

---

## 1. 目的

小児循環器診療(病棟・外来・当直・救急)の現場で**即座に参照できる**実践的ポケットマニュアルを作成し、Notion 上で複数医師が共有・共同運用できるようにする。

## 2. 利用者・利用シーン(2026-08-04 更新)

**利用者は小児循環器医、使用施設は小児循環器専門施設を想定する。**

| 利用者 | 主な利用シーン |
|---|---|
| 小児循環器医 | 急性期対応フロー・薬剤用量の即時確認、外来フォロー計画、慢性期治療方針の確認 |
| 小児循環器を研修中の専攻医 | 指導医の監督下での疾患の全体像把握、検査計画の立案 |

### 記載上の前提

- カテーテル検査・EPS/アブレーション・小児心臓外科・集中治療(MCS 含む)が**自施設内で完結する**前提で書く。
- 「小児循環器専門施設へ搬送」「専門医へ紹介・相談」といった**転送前提の文言は使わない**。エスカレーションは**院内連携**(集中治療・心臓血管外科・カテ室・不整脈チーム等)として記載する。

## 3. スコープ(整備順)

### フェーズ1(優先領域 — 決定済み)
1. **先天性心疾患**(VSD / ASD / PDA / TOF / TGA / 単心室・Fontan / CoA など)
2. **心不全・心筋症・肺高血圧**(急性心不全 / 慢性心不全 / DCM / HCM / 心筋炎 / PAH)
3. **不整脈**(SVT / WPW / VT / QT延長症候群 / 房室ブロック など)

### フェーズ2(将来)
- 川崎病、感染性心内膜炎、失神・胸痛の外来アプローチ、学校心臓検診二次精査 など

詳細な疾患リストと優先順位は `10_疾患リスト_ロードマップ.md` を参照。

## 4. 疾患ページの標準構成(全疾患共通テンプレート)

### 4.0 構成拡張(2026-08-04 採用決定)

以下4案をすべて採用する:

1. **2層構成**: 各疾患ページ冒頭に「🚑クイックカード(1画面完結の当直用フロー+急性期用量)」を置き、その下に詳細10項を続ける
2. **薬剤DB分離**: 薬物用量の正本は `drugs/薬剤DB.csv`(Notion ではデータベース)。疾患ページには役割・要点のみ記載し、用量を直書きしない。添付文書改訂時は DB の1箇所を直せば全体に反映される
3. **症状からの逆引きインデックス**: `index/症状からの逆引き.md`。主訴・所見・場面から該当ページへ誘導。新ページ作成のたびに更新する
4. **共通アペンディクス**: 複数疾患から参照される横断的内容(学校生活管理指導表・IE予防・パリビズマブ・基準値など)は `appendix/` に集約し、疾患ページからリンクする

全疾患ページは以下の10項構成に統一する(`templates/疾患テンプレート.md` 参照):

1. 疾患概略(定義・疫学・自然歴・血行動態)
2. 診断のポイント(症状・身体所見・鑑別診断)
3. 特徴的な検査所見(心電図 / 胸部X線 / 心エコー / カテーテル / バイオマーカー / その他)
4. 急性期治療(初期対応フロー・適応基準)
5. 慢性期治療計画(内科管理・手術/カテーテル治療の適応とタイミング)
6. 薬物の小児用量(出典必須・適応外使用フラグ必須)
7. 外来診療への移行(退院基準・移行時チェックリスト)
8. 外来診療のポイント(受診間隔・警告症状・運動制限/学校生活管理指導表・IE予防・予防接種)
9. 検査計画の流れ(フォロー間隔×モダリティのマトリクス)
10. 出典一覧・最終確認日・執筆者/校閲者

## 5. 事実性の担保(最重要要件)

### 5.1 情報源の優先順位(決定済み: 日本の基準を最優先)

| 優先度 | 情報源 | 用途 |
|---|---|---|
| 1 | 日本循環器学会(JCS)・日本小児循環器学会(JSPCCS)等の合同ガイドライン | 診断基準・治療方針の正本 |
| 2 | 学会の診療の手引き・提言・ステートメント | ガイドライン未整備領域の補完 |
| 3 | PMDA 添付文書 | **薬剤用量は必ず添付文書と照合**。ガイドライン推奨用量と乖離がある場合は両方併記 |
| 4 | 国際ガイドライン(AHA / ACC / ESC / PALS) | 日本のガイドラインに記載のない事項の補足(補足である旨を明記) |

### 5.2 記載ルール

- すべての推奨・数値(用量・基準値・フォロー間隔)に**出典を明記**する(ガイドライン名・発行年・可能なら CQ 番号/表番号)。
- 薬剤用量には以下を必ず付記する:
  - 出典(添付文書 or ガイドライン、両方併記が原則)
  - **小児適応の有無**(適応外使用は `⚠️適応外` フラグを付ける)
  - 剤形・投与経路・最大量・調整方法(腎機能等)
- 出典が確認できない記載は掲載しない。経験的・施設的な運用は「施設ルール」として出典情報と明確に区別する。
- 各ページに「最終確認日」と「確認したガイドライン/添付文書の版」を記載する。

### 5.3 校閲ワークフロー

```
[ドラフト作成(Claude)] → [一次校閲(担当医師)] → [承認(責任医師)] → [Notion 公開]
```

- ステータス管理: `ドラフト` → `校閲中` → `承認済み` → `要改訂`
- **「承認済み」以外のページは診療に使用しない**ことを全ページ冒頭に明示する。
- ガイドライン改訂・添付文書改訂時は該当ページを `要改訂` に戻す。
- 年1回、全ページの定期見直しを行う(最終確認日から1年超のページを洗い出す)。

### 5.4 免責の明示

各ページ冒頭に以下を固定表示する:

> 本マニュアルは診療の参考情報であり、個々の患者への適用は担当医の判断と責任において行うこと。薬剤使用時は必ず最新の添付文書を確認すること。

## 6. Notion 連携(決定済み: まず手動インポート)

### 6.1 運用方式

- **正本(マスター)は本 GitHub リポジトリの Markdown** とする。改訂履歴・校閲コメントは GitHub 側に残る。
- 承認済みページを Notion に手動インポート(`Settings & Members → Import → Markdown` またはページ単位の `/import`)して共有する。
- Markdown は Notion インポートで崩れない記法に限定する(見出し・表・箇条書き・引用・区切り線。HTML タグ・脚注記法は使わない)。

### 6.2 Notion 側の推奨構成

- トップページ「小児循環器ポケットマニュアル」配下に領域別サブページ(先天性心疾患 / 心不全・心筋症・肺高血圧 / 不整脈)
- 疾患一覧はデータベース化し、以下のプロパティを持たせる:
  - 疾患名 / 領域 / ステータス(ドラフト・校閲中・承認済み・要改訂)/ 最終確認日 / 校閲者 / 主要出典
- メンバー権限: 編集は校閲担当医師のみ、他は閲覧+コメント

### 6.3 将来の拡張

運用が安定したら、Notion API による自動同期スクリプト(GitHub → Notion)への移行を検討する(方式B)。

## 7. ファイル・命名規則

```
pocket-manual/
├── docs/            … 要件定義・運用ルール・ロードマップ
├── templates/       … 疾患ページテンプレート
└── chapters/
    ├── 01_先天性心疾患/       … 例: VSD_心室中隔欠損.md
    ├── 02_心不全_心筋症_肺高血圧/
    └── 03_不整脈/
```

- ファイル名: `略語_日本語正式名.md`(例: `TOF_ファロー四徴症.md`)
- 1疾患1ファイル。共通事項(IE予防、学校生活管理指導表の使い方など)は横断ページとして別ファイル化し、各疾患ページからリンクする。

## 8. 非機能要件

- ポケットマニュアルとして**1疾患ページは印刷 A4 で 2〜4 枚程度**に収める(詳細はガイドライン原典へ誘導)。
- スマートフォンの Notion アプリで読みやすいこと(表の列数は4列以内を目安)。

### 8.1 記載スタイル(視認性優先・2026-08-04 決定)

**全ページで箇条書きを主体とし、文章は最低限にする。** 具体ルール:

- 1項目=1行を目安(体言止め可)。段落文が3行以上続いたら箇条書きに割る。
- 用量・基準値・カットオフは**太字**。判断の分岐は「→」で示す。
- 視認マーク: ⛔=禁止/回避、⚠️=注意、⚠️適応外=適応外使用、📎=関連リンク。
- 出典は〔GL名〕で末尾に簡潔に。未照合は【要校閲】。
- ヘッダのメタ情報(領域・ステータス・最終確認日・執筆/校閲)は縦長にせず**表1行**にまとめる。
- この方針はテンプレート冒頭のコメントにも記載し、全疾患ページで踏襲する。

## 9. 運用体制(2026-08-04 決定)

- **責任医師(最終承認者)**: 発起人医師(本マニュアルのオーナー)
- **位置づけ**: 病院・施設とは無関係の**非公式・私的な参考資料**。施設公式プロトコルではないことを全ページの免責文で明示する。
- 校閲は当面責任医師が兼任。共有メンバーが増えた時点で領域別校閲担当を割り当てる。

## 10. 執筆時の制約と対応(運用メモ)

- 執筆環境からはガイドライン PDF・添付文書の原文に直接アクセスできない場合がある。その場合、ドラフト内の該当箇所に **【要校閲】** フラグを付け、原典名を明記する。責任医師が原典(ガイドライン本文・PMDA 添付文書)と照合し、フラグを外した時点で「承認済み」にできる。
- 【要校閲】フラグが1つでも残るページは「校閲中」より先に進めない。
