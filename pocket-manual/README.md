# 小児循環器ポケットマニュアル

小児循環器診療(病棟・外来・当直)向けの実践ポケットマニュアル。
**正本(マスター)は本リポジトリの Markdown** で、承認済みページを Notion にインポートして複数医師で共有する。

## 構成

```
pocket-manual/
├── docs/
│   ├── 00_要件定義.md              … 目的・構成・事実性担保ルール・運用フロー
│   └── 10_疾患リスト_ロードマップ.md … 対象疾患と整備優先順位
├── templates/
│   └── 疾患テンプレート.md          … 全疾患共通の10項構成テンプレート
├── index/
│   └── 症状からの逆引き.md          … 主訴・所見から疾患ページへ飛ぶ入口
├── drugs/
│   ├── 薬剤DB.csv                  … 薬物用量の正本(Notionにデータベースとして取込)
│   └── README.md                   … DB の列定義・運用ルール
├── appendix/
│   └── 共通_学校生活管理指導表.md    … 全疾患横断の共通ページ(今後追加)
└── chapters/
    ├── 01_先天性心疾患/
    ├── 02_心不全_心筋症_肺高血圧/
    └── 03_不整脈/
        └── SVT_上室頻拍.md         … 冒頭に🚑クイックカード(当直用)+詳細10項
```

## ページ構成の原則(2026-08-04 採用)

1. **2層構成**: 各疾患ページは冒頭に「🚑クイックカード(1画面の当直用フロー)」、その下に詳細10項
2. **薬剤DB分離**: 用量の正本は `drugs/薬剤DB.csv`。疾患ページには役割と要点のみ書き、用量を直書きしない
3. **逆引きインデックス**: `index/症状からの逆引き.md` を Notion トップ直下に置き、新ページ作成のたびに更新
4. **共通アペンディクス**: 複数疾患から参照される内容(管理指導表・IE予防等)は `appendix/` に横断ページ化

## 大原則

1. **全記載に出典必須**(日本のガイドライン → 学会手引き → PMDA 添付文書 → 国際ガイドラインの優先順)
2. **薬剤用量は必ず添付文書と照合**し、適応外使用には ⚠️ フラグを付ける
3. **「承認済み」ステータス以外のページは診療に使用しない**
4. 各ページに最終確認日・確認した出典の版・校閲者を記録する

## Notion への取り込み方(手動インポート)

1. Notion で取り込み先ページを開く
2. `⋯` メニュー → `Import` → `Markdown & CSV` を選択(または新規ページで `/import`)
3. 対象の `.md` ファイルを選択(複数選択可)。**`drugs/薬剤DB.csv` は CSV としてインポートするとデータベース(1行=1薬剤ページ)になる**
4. インポート後、疾患一覧データベースにページをリンクし、プロパティ(ステータス・最終確認日・校閲者)を設定
5. `index/症状からの逆引き.md` はトップページ直下に置き、表内の参照先を Notion 内リンクに張り替える(Markdown の相対リンクはインポートで無効になるため)

※ 本リポジトリの Markdown は Notion インポートで崩れない記法(見出し・表・箇条書き・引用・区切り線)に限定している。

## 更新フロー

```
GitHub でドラフト作成 → 医師校閲 → 承認 → Notion にインポート(再インポート時は旧ページを置換)
```
