## 🚑 クイックカード(外来・当直用・1画面)

- **大前提**: 大半は経過観察でよい。**血行動態(欠損の大きさ・Qp/Qs・肺高血圧)と合併症(AR・IE)で方針が決まる。**
- **① 心不全徴候の乳児**(多呼吸・哺乳不良・体重増加不良・発汗)
  - → 利尿薬(フロセミド)+ ACE阻害薬 → 高カロリー栄養 → 反応不良なら早期手術
- **② 大欠損・高肺血流**
  - → **2歳までに手術**(肺血管閉塞性病変の進行予防)【要校閲: 時期を原典確認】
- **③ 小欠損・無症状**
  - → 経過観察。**IE予防**と自然閉鎖のフォロー
- **④ 大動脈弁逸脱/AR 出現**(高位欠損)
  - → ⚠️ AR は不可逆化前に手術適応。サイズが小さくても適応になりうる
- **⑤ 高度肺高血圧・Eisenmenger 化**
  - → ⛔ 閉鎖術は禁忌になりうる。手術適応を慎重評価【要校閲】

## 1. 疾患概略

- **定義**: 心室中隔の欠損孔による左→右短絡
- **疫学**: 先天性心疾患で最多【要校閲: 頻度を原典確認】
- **分類(Kirklin)**
  - I型: 漏斗部(動脈弁下)— **日本人に多い**、AR 合併リスク
  - II型: 膜性部(傍膜様部)— 最多
  - III型: 流入部(心内膜床型)
  - IV型: 筋性部 — 自然閉鎖しやすい
- **血行動態**: 欠損サイズと肺血管抵抗で短絡量が決まる → 容量負荷(左房・左室)
- **自然歴**: 小〜中欠損は自然閉鎖が多い
  - 生後6か月までは比較的大きい欠損でも閉鎖率が高い(>40%)、5歳超で<10%【要校閲: 数値を原典確認】

## 2. 診断のポイント

- **心雑音**: 胸骨左縁下部の全収縮期雑音(小欠損ほど高調・大きい)
- **大欠損の心不全徴候(乳児)**: 多呼吸・哺乳不良・体重増加不良・発汗・肝腫大
- **身体所見**: 短絡大で II音亢進(肺高血圧)、心尖部拡張期ランブル(僧帽弁流量増加)
- **⚠️ ピットフォール**
  - 雑音が減弱 → 「閉鎖」だけでなく **肺高血圧進行(短絡減少)** の可能性
  - 高位欠損では **大動脈弁逸脱・AR の新規出現**を必ずチェック

## 3. 特徴的な検査所見

| 検査 | 特徴的所見 |
|---|---|
| 心電図 | 大欠損: 左室/両室肥大。肺高血圧進行で右室肥大優位 |
| 胸部X線 | 心拡大・肺血管陰影増強(短絡大)。Eisenmenger化で末梢肺血管の減少 |
| 心エコー | 欠損の位置・サイズ、短絡方向、Qp/Qs、左房・左室容量、推定右室/肺動脈圧、AR の有無 |
| 心臓カテーテル | 手術適応の境界例・肺高血圧評価(肺血管抵抗・反応性)。ルーチンではない |
| 採血 | 心不全評価に BNP/NT-proBNP(年齢別基準に注意) |

## 4. 急性期治療(心不全のコントロール)

- **判断軸**: 手術までの橋渡し(bridge)としての内科管理。反応不良は手術時期の前倒し
- **手順**
  1. 利尿薬: フロセミド(±スピロノラクトン)で容量負荷を軽減
  2. 後負荷軽減: ACE阻害薬(エナラプリル等)で左→右短絡を減らす【要校閲: 小児は適応外】
  3. 栄養強化: 高カロリー(経管栄養含む)で体重増加を確保
  4. ジゴキシン: 追加を検討(施設により)【要校閲】
  5. 反応不良・体重増加不良の持続 → 早期手術へ
- **院内エスカレーション基準**(集中治療・心臓血管外科・カテ室)
  - 内科治療抵抗性の心不全、著明な発育不良 → 心臓血管外科と手術時期を協議
  - 肺高血圧の評価が必要な境界例 → カテ室で肺血管抵抗・反応性を評価

## 5. 慢性期治療計画(手術/カテーテル)

- **外科的閉鎖の主な適応**【要校閲: 基準を原典確認】
  - 症候性の大欠損・治療抵抗性心不全
  - **Qp/Qs > 2.0**(容量負荷大)/ 1.5〜2.0 は症状・肺血管抵抗で判断
  - 大動脈弁逸脱・AR の出現(⚠️ 小欠損でも適応)
  - IE の既往
- **手術時期**: 大欠損・高肺血流は **2歳までに**(肺血管閉塞性病変の進行予防)【要校閲】
- **⛔ 手術非適応**: 高度肺高血圧・Eisenmenger 化(閉鎖で右心不全悪化)【要校閲】
- **カテーテル閉鎖**: 筋性部・一部の傍膜様部で適応(施設・デバイスによる)【要校閲】

## 7. 外来診療への移行

- **退院基準(案)**: 心不全コントロール良好 / 体重増加が確保 / 内服と栄養を家族が管理可
- **移行時チェック**
  - [ ] 内服(利尿薬・ACE阻害薬)の用量・電解質フォロー計画を家族に説明
  - [ ] 体重増加(発育曲線)のモニタ方法を説明
  - [ ] IE予防(歯科処置時等)の必要性を説明
  - [ ] 増悪時の受診基準(哺乳低下・多呼吸・体重増加不良)を説明
  - [ ] 次回外来・心エコーの予約

## 8. 外来診療のポイント

- **受診間隔**: 大欠損・術前は 1〜2か月毎、小欠損は 6〜12か月毎(自然閉鎖・AR を確認)【要校閲】
- **毎回確認**: 体重増加(発育曲線)、心雑音の変化、心不全徴候、II音、AR の新規雑音
- **IE予防**: 未閉鎖 VSD・パッチ閉鎖後の遺残短絡などは適応。歯科処置前の抗菌薬〔IE予防GL〕【要校閲】
- **運動制限**: 小欠損・心機能正常なら原則不要。肺高血圧・AR 合併は個別に管理指導表で判断【要校閲】
- **予防接種・RSV(パリビズマブ)**: 心不全を伴う血行動態的に重要な CHD で適応を検討【要校閲】
- **⚠️ AR の監視**: 高位欠損では受診毎に大動脈弁を評価(進行前の手術判断)
