## 🚑 クイックカード(当直・ICU用・1画面)

- **大前提**: まず**血行動態プロファイル**を分類 → 治療を選ぶ。**原因検索(心筋炎・不整脈・構造異常・代謝)を並行。**
  - Warm/Dry=代償、Warm/Wet=うっ血、**Cold/Wet=低灌流+うっ血**、**Cold/Dry=低灌流**(Nohria分類)
- **① 初期対応**: ABC・モニタ・静脈路 → SpO2/血圧/尿量 → 12誘導・心エコー・採血(BNP・乳酸・トロポニン)
- **② うっ血(Wet)** → **フロセミド**静注で除水。呼吸補助(酸素・NPPV/挿管)
- **③ 低灌流(Cold)** → **強心薬**: ドブタミン or ミルリノン(PDE III)。血圧低下時はドパミン/アドレナリン
- **④ 反応不良・進行性** → ⚠️ 早期に **MCS(ECMO/補助循環)** を考慮。ICU・心臓血管外科と共有
- **⑤ 是正すべき誘因**: 不整脈(SVT/VT/ブロック)・電解質・貧血・感染・動脈管依存病変(→PGE1)
- **⛔ 注意**: 過剰輸液を避ける / 診断確定前の安易なβ遮断薬は不可(急性期は禁忌になりうる)

## 1. 疾患概略

- **定義**: 心拍出量の低下・体静脈/肺静脈うっ血が急性に出現・増悪した状態
- **主な原因(年齢別)**
  - 新生児: 動脈管依存性の左心閉塞性病変(CoA/IAA/HLHS)、重症AS、大きな左→右短絡
  - 乳児: 大きな左→右短絡(VSD等)、心筋炎、頻拍誘発性心筋症、代謝性
  - 年長児: 心筋炎、拡張型心筋症、不整脈、川崎病後遠隔期、化学療法後
- **病態**: 前負荷・後負荷・収縮/拡張能・心拍数のいずれかの破綻。低灌流とうっ血の組み合わせで分類

## 2. 診断のポイント

- **低灌流(Cold)**: 四肢冷感・網状皮斑・毛細血管再充満延長・尿量減少・意識低下・乳酸上昇
- **うっ血(Wet)**: 多呼吸・肝腫大・浮腫・体重増加・肺ラ音(年長児)・頸静脈怒張(年長児)
- **乳児の心不全徴候**: 哺乳不良・発汗(哺乳時)・体重増加不良・多呼吸・肝腫大
- **⚠️ ピットフォール**
  - 「感冒・胃腸炎」に見える心筋炎(不機嫌・嘔吐・頻脈・末梢冷感)を見逃さない
  - 新生児のショックは**動脈管依存病変**を鑑別(四肢血圧差・下肢SpO2低下 → PGE1)
  - SVT の遷延による頻拍誘発性心筋症(まず頻拍の停止)

## 3. 特徴的な検査所見

| 検査 | 特徴的所見 |
|---|---|
| 心エコー | 心機能(EF/FS)・心拡大・弁逆流・心嚢液・構造異常・下大静脈径。**原因診断の中心** |
| 心電図 | 頻脈、低電位・ST-T変化(心筋炎)、心室肥大、不整脈、房室ブロック |
| 胸部X線 | 心拡大・肺うっ血・胸水 |
| 採血 | BNP/NT-proBNP↑(年齢別基準)、トロポニン↑(心筋炎)、乳酸↑(低灌流)、電解質・腎/肝機能・血糖 |
| その他 | 血液ガス、感染・代謝スクリーニング、必要に応じ心臓MRI・心筋生検(専門的) |

## 4. 急性期治療

- **判断軸**: 血行動態プロファイル(Cold/Warm × Wet/Dry)で治療を選択。原因是正を並行
- **手順**
  1. **初期安定化**: 酸素・呼吸補助(NPPV/挿管)、モニタ、静脈路。過剰輸液を避ける
  2. **うっ血(Wet)**: フロセミド静注(反応不良は持続静注を検討)【要校閲】。塩分・水分制限
  3. **低灌流(Cold)**: 強心薬 — ドブタミン or ミルリノン(PDE III)。低血圧併発はドパミン/アドレナリン、後負荷過剰は血管拡張薬(慎重に)
  4. **誘因是正**: 不整脈治療(SVT→停止、徐脈→ペーシング)、電解質補正、貧血・感染治療、動脈管依存病変→PGE1
  5. **難治・進行性**: MCS(ECMO/補助人工心臓)を早期に検討 → 移植適応の評価へ
- **院内エスカレーション基準**(集中治療・心臓血管外科・カテ室)
  - **入院・ICU**: 強心薬を要する低灌流、呼吸補助を要するうっ血、意識障害・乳酸上昇
  - **MCS/移植チームと共有**: 強心薬増量でも改善しない、末梢臓器障害の進行、劇症型心筋炎

## 5. 慢性期への移行

- 急性期を離脱したら、原因に応じた**慢性心不全の管理**へ移行 → [慢性心不全](CHF_慢性心不全.md)
- 強心薬からの離脱に伴い、忍容性を見ながら経口薬(ACE阻害薬・β遮断薬・利尿薬・MRA)を導入【要校閲: 導入順・時期】

## 7. 外来診療への移行

- **退院基準(案)**: 強心薬を離脱し血行動態が安定 / 経口心不全薬に忍容性 / 家族が症状・体重・内服を管理可
- **移行時チェック**
  - [ ] 原因が特定・是正されている(または慢性管理計画がある)
  - [ ] 経口薬(ACE阻害薬・β遮断薬・利尿薬・MRA)の用量と副作用を家族に説明
  - [ ] 体重・症状(哺乳・多呼吸・浮腫)のモニタ方法を説明
  - [ ] 増悪時の受診基準・緊急連絡先を説明
  - [ ] 次回外来・心エコー・採血(BNP)の予約

## 8. 外来診療のポイント

- **受診間隔**: 導入・増量期は 1〜2週〜1か月毎、安定後は延長【要校閲】
- **毎回確認**: 体重(発育曲線)、症状、血圧・心拍数、内服アドヒアランス、電解質・腎機能(利尿薬/ACE阻害薬)
- **⚠️ 増悪の早期サイン**: 体重増加・多呼吸・哺乳低下・浮腫・活気低下
- **予防接種・RSV(パリビズマブ)**: 血行動態的に重要な心不全で適応を検討【要校閲】
- 詳細な慢性管理は [慢性心不全](CHF_慢性心不全.md) を参照
