## 🚑 クイックカード(当直用・1画面)

- **大前提**: wide QRS は原則 VT として対応 / 全経過で心電図記録(機序診断の証拠)
- **① 不安定**(ショック・意識障害・重度心不全)
  - → 同期下カルディオバージョン **0.5〜1 J/kg** → 無効 **2 J/kg**【要校閲】
  - 意識あれば鎮静先行
- **② 安定 → 迷走神経刺激**
  - 乳児: 顔面に氷水バッグ数秒 / 年長児: Valsalva
  - ⛔ 眼球圧迫は禁止
- **③ 無効 → ATP 0.1 mg/kg 急速静注+生食後押し**(⚠️適応外)
  - 無効 → 0.2 → 0.3 mg/kg【要校閲】
  - 喘息は回避 / 心電図記録しながら
- **④ 無効・年長児 → ベラパミル 0.1〜0.2 mg/kg(max 5 mg)を5分以上かけ静注**
  - ⛔ 新生児・乳児は原則使用しない
- **⑤ 停止後 → 12誘導でデルタ波(WPW)確認** / 初発は心エコー
- **⑥ 反復・薬物無効 →** 他剤切替・早期アブレーション検討 / 心機能低下は ICU

## 1. 疾患概略

- **定義**: His束分岐部より上位(心房・房室接合部)を回路/起源とする頻拍
  - 狭義: AVRT・AVNRT・心房頻拍(AT)
- **疫学**: 小児で最多の頻脈性不整脈
  - 乳児期: AVRT(副伝導路)が最多 / 学童期以降: AVNRT 増加【要校閲: 頻度を原文確認】
- **病態**: 多くはリエントリー
  - 基礎心疾患なしが大半。ただし Ebstein病・修正大血管転位は副伝導路合併多 → 初発時に基礎疾患検索【要校閲】
- **自然歴**: 乳児期発症は1歳頃に高率に消失(学童期に再発あり)【要校閲: 数値を原文確認】

## 2. 診断のポイント

- **乳児**: 症状非特異的(不機嫌・哺乳不良・多呼吸・顔色不良)
  - 長時間持続で心不全発見あり → 原因不明のぐったり・頻脈で必ず12誘導
- **年長児**: 突然始まり突然終わる動悸(発作性)
- **心拍数目安**: 乳児 ≧220/分、年長児 ≧180/分 で強く疑う〔JRC2020 PLS〕【要校閲】
- **洞性頻脈との鑑別**
  - 洞性: 誘因あり(発熱・脱水・出血)・変動する・P波洞調律軸
  - SVT: 変動乏しい・突然開始/停止
- **⚠️ ピットフォール**
  - 停止後心電図でデルタ波(WPW)を必ず確認
  - wide QRS は原則 VT 対応(変行伝導と安易に判断しない)

## 3. 特徴的な検査所見

| 検査 | 特徴的所見 |
|---|---|
| 発作時心電図 | narrow QRS の規則的頻拍。RP間隔とP′波位置で機序推定(short RP: AVRT/AVNRT) |
| 停止後心電図 | デルタ波・PQ短縮(WPW)、QT延長・基礎疾患の除外 |
| 心エコー | 基礎心疾患(Ebstein等)除外、頻拍誘発性心筋症の評価 |
| ホルター | 発作頻度・非持続性頻拍・デルタ波の間欠性 |
| 採血 | 長時間発作でBNP/トロポニン・乳酸、電解質・甲状腺機能 |
| EPS | アブレーション適応評価・無症候性WPWのリスク層別化 |

## 4. 急性期治療

- **判断軸**: 血行動態 不安定 → カルディオバージョン / 安定 → 迷走神経刺激 → ATP
- **手順**
  1. 初期評価: ABC・SpO2・血圧・意識 / 静脈路 / 12誘導記録開始
  2. 迷走神経刺激(安定例)
     - 乳児: 氷水バッグを前額〜顔面に数秒(dive reflex)
     - 年長児: Valsalva(改良Valsalva 含む)
     - ⛔ 眼球圧迫は不可(網膜剥離等)/ 頸動脈洞マッサージは小児で推奨度低【要校閲】
  3. ATP: 心臓に近い太い静脈から急速静注+生食後押し / 無効なら段階増量
  4. ATP無効・再発: 年長児はベラパミル(新生児・乳児は原則不可)/ 他剤(プロカインアミド・アミオダロン等)切替【要校閲: 推奨順を原典確認】
  5. 不安定 or 薬物無効: 同期下カルディオバージョン 0.5〜1 J/kg → 無効 2 J/kg / 意識あれば鎮静先行〔JRC2020〕【要校閲】
  6. 停止後: 12誘導(デルタ波)/ 初発は心エコー / 頻拍誘発性心筋症疑いは入院

### 院内エスカレーション基準(案)

- **入院・ICU 検討**: カルディオバージョン施行例、心機能低下(頻拍誘発性心筋症疑い)、新生児・乳児の遷延例、循環不全合併
- **不整脈チーム・カテ室と共有**: 薬物抵抗性の反復例(早期アブレーション)、wide QRS 例(機序診断)

## 5. 慢性期治療計画

- **乳児期発症**: β遮断薬(プロプラノロール等)で再発予防 → 1歳前後で消失多く中止検討【要校閲】
- **顕性WPW合併**: ジゴキシン・ベラパミル単独長期投与は避ける(AF時の副伝導路伝導促進)【要校閲】
- **学童期以降・再発例**: カテーテルアブレーション適応を検討(体格・発作頻度・薬物反応・希望)〔非薬物治療GL 2018〕【要校閲: 体重・年齢基準を原典確認】
- **無症候性WPW(検診発見)**: リスク層別化(間欠性デルタ波・運動負荷での消失・EPS)→ アブレーション適応判断【要校閲】

| 薬剤(→薬剤DB) | 役割 | 要点 |
|---|---|---|
| ATP(アデホス-Lコーワ注) | 発作停止・第一選択 | ⚠️適応外。急速静注+生食後押し。喘息回避 |
| ベラパミル(ワソラン静注) | 発作停止・第二選択(年長児) | ⛔新生児・乳児は原則不可。5分以上かけ静注 |
| プロプラノロール(インデラル) | 再発予防・第一選択 | 小児適応あり。喘息禁忌・乳児は低血糖注意【要校閲】 |
| フレカイニド(タンボコール) | 再発予防・難治例 | 小児適応あり。器質的心疾患で催不整脈注意【要校閲】 |

## 7. 外来診療への移行

- **退院基準(案)**: 発作停止確認 / 心機能保持〜回復傾向 / 家族が発作時対応を説明可
- **移行時チェック**
  - [ ] 停止後12誘導でデルタ波を確認・記録
  - [ ] 初発例: 心エコーで基礎疾患除外
  - [ ] 予防投与の要否決定 → 用量・中止予定を家族に説明
  - [ ] 家庭での発作時対応(§8)と受診基準を説明
  - [ ] 次回外来・検査(心電図/ホルター)予約

## 8. 外来診療のポイント

- **受診間隔**: 内服中 1〜3か月毎(調整期は短く)/ 中止後は再発なければ延長【要校閲】
- **毎回確認**: 発作の有無・頻度・持続、内服アドヒアランス、体重(用量再計算)、心拍数・心電図
- **家族への発作時指導**: 年長児=自己停止手技(Valsalva)/ 乳児=顔面冷却
  - 救急受診: ぐったり・顔色不良・30分以上持続
- **運動制限**: コントロール良好・基礎疾患なしなら原則不要のことが多い
  - WPW合併・失神歴 → 運動負荷試験を踏まえ管理指導表の区分判断〔学校心臓検診GL〕【要校閲】
- **IE予防**: 基礎心疾患なければ不要
- **⚠️ 用量再計算**: 成長でmg/kg目減り → 発作再発の一因
