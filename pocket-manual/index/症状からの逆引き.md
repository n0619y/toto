## 🚨 緊急対応系

| 症状・所見 | まず疑う/確認すること | 参照ページ |
|---|---|---|
| 頻脈(narrow QRS・規則的) | SVT。不安定ならカルディオバージョン | [SVT_上室頻拍](../chapters/03_不整脈/SVT_上室頻拍.md) 🚑クイックカード |
| 頻脈(wide QRS) | **原則 VT として対応** | VT_心室頻拍(未作成・★★★) |
| チアノーゼ発作(無酸素発作) | TOF スペル。膝胸位・酸素・鎮静 | TOF_ファロー四徴症(未作成・★★★) |
| 生後1〜3週の急激なショック・多臓器不全 | 動脈管閉鎖に伴う左心閉塞性疾患(CoA/IAA/HLHS)。PGE1 開始を検討 | CoA_大動脈縮窄(未作成)/ 共通_動脈管依存性疾患_PGE1(未作成・★★★) |
| 新生児の全身チアノーゼ(酸素で改善しない) | TGA など動脈管依存性チアノーゼ性心疾患。PGE1 | TGA_完全大血管転位(未作成・★★★) |
| 乳児のぐったり・哺乳不良・多呼吸 | 心不全(心筋炎・DCM・長時間 SVT)。12誘導心電図+エコー | AHF_急性心不全(未作成・★★★)/ Myocarditis_心筋炎(未作成・★★★) |
| 感冒症状後の不整脈・心電図変化・ショック | 劇症型心筋炎。早期に ICU・MCS(ECMO)チームと共有 | Myocarditis_心筋炎(未作成・★★★) |
| 徐脈(高度・失神を伴う) | 完全房室ブロック | CAVB_完全房室ブロック(未作成・★★) |

## 🩺 外来・検診系

| 症状・所見 | まず疑う/確認すること | 参照ページ |
|---|---|---|
| 運動中・驚愕時の失神 | LQTS・カテコラミン誘発性 VT など致死性不整脈を除外 | LQTS_QT延長症候群(未作成・★★) |
| 動悸(突然始まり突然終わる) | SVT。発作時心電図の記録方法を指導 | [SVT_上室頻拍](../chapters/03_不整脈/SVT_上室頻拍.md) |
| 心雑音(無症状・乳児健診/学校検診) | VSD・ASD・PS など。心エコーへ | VSD/ASD/PS(未作成) |
| 学校心電図検診での異常(デルタ波) | 無症候性 WPW のリスク層別化 | WPW_WPW症候群(未作成・★★★) |
| 学校心電図検診での異常(QT延長) | LQTS。運動制限・禁忌薬の確認 | LQTS_QT延長症候群(未作成・★★) |
| 胸痛 | 多くは非心臓性。red flag(労作時・失神合併・家族歴)を確認 | 胸痛アプローチ(フェーズ2) |
| 期外収縮の指摘 | PAC/PVC。多くは経過観察可 | PVC_期外収縮(未作成・★) |
