# AIが可能にする酷暑対策 新規事業提案書

作成日: 2026-07-23
作成: AI事業企画ドラフト（要・事業主体によるレビュー）

---

## 1. エグゼクティブサマリー

- 2025年夏（5〜9月）の熱中症救急搬送者数は **100,510人と統計開始以来過去最多** を記録し、酷暑は一過性の異常気象ではなく**構造的・恒常的な社会課題**になった。
- 2025年6月1日施行の改正労働安全衛生規則により、**職場の熱中症対策が事業者の法的義務**となり、WBGT計測・体制整備・教育に対する企業需要と補助金が急拡大している。
- 一方で搬送者の約57%は高齢者、また乳幼児・児童は「自分で症状を訴えられない／周囲の大人の判断に依存する」ハイリスク層であり、**家庭・保育園・学校・自治体向けの予防領域はソリューション空白地帯**が大きい。
- 本提案では、AIを核とした酷暑対策の新規事業アイデア7案を比較評価し、既存資産（小児科医監修体制＋AIコンテンツ自動生成システム）とのシナジーが最も高い **「こども熱中症AI予防プラットフォーム（仮称：ヒートセーフこども）」を最優先案** として推奨する。

## 2. 市場環境と事業機会

### 2.1 酷暑の恒常化（Why now）

| 項目 | 内容 |
|---|---|
| 救急搬送者数（2025年5〜9月） | 100,510人（過去最多、前年比+2,932人） |
| 年齢別内訳 | 高齢者57.1% / 成人33.9% / 少年8.4% / 乳幼児0.5% |
| 特徴 | 2025年は梅雨明けが統計開始以降最早の地方が多く、6月の搬送17,229人は月別過去最多。暑さの「立ち上がりの早期化」「二季化」が進行 |

### 2.2 規制・政策ドライバー

- **改正労働安全衛生規則（2025年6月1日施行）**: 職場の熱中症対策（発見・報告体制、重篤化防止手順の整備等）が罰則付きで義務化。
- **補助金の拡充（2026年度）**: WBGTセンサー・見える化・通知システム導入に対する国・自治体の補助制度が多数（導入費最大100万円補助の例あり）。
- **自治体のAI受容度向上**: AI・RPA導入済み自治体は74%に達し、東京都は2026年度から全職員向け生成AI基盤を本格運用。自治体がAIサービスを調達する土壌が整った。

### 2.3 構造的な空白地帯

1. **職場向け（B2B）**: 義務化でプレイヤー急増中（AIカメラ・WBGTセンサー等）だが、「教育・行動変容」のコンテンツ面は手薄。
2. **こども向け（B2B2C）**: 保育園・幼稚園・学校・学童の現場は、判断基準の属人化・保護者への説明負担が課題。医学的に正しい情報を現場の言葉に翻訳するプレイヤーがいない。
3. **高齢者向け（B2G）**: 搬送者の過半数を占めるが、独居高齢者への声かけ・見守りは人手不足。自治体は「アウトリーチのDX」を求めている。

## 4. 最優先案の詳細: こども熱中症AI予防プラットフォーム（仮称: ヒートセーフこども）

### 4.1 解決する課題

| 顧客 | 現状の痛み |
|---|---|
| 保育園・幼稚園・学童 | 「今日は外遊びをして良いか」の判断が園長の経験頼み。保護者への説明責任・クレーム対応の負担が重い |
| 学校（養護教諭・部活動） | WBGT値は測れても「学年・活動別に何をどう制限するか」の翻訳ができない |
| 保護者 | SNS上の不正確な情報が氾濫。乳幼児は症状を訴えられず、受診判断に迷う |

### 4.2 ソリューション（3層構成）

1. **毎朝のAIリスクブリーフ（施設向け）**
   - 気象予報・WBGT予測×施設属性（園庭の日陰率、年齢構成）から、その日の活動可否・水分補給スケジュール・観察ポイントを自動生成し、毎朝7時に配信。
   - 「本日の保護者向けお知らせ文」もワンクリック生成（連絡帳アプリ・LINEにそのまま貼れる）。
2. **小児科医監修コンテンツエンジン（保護者向け）**
   - 既存のコンテンツ自動生成システム（テーマ選定→リサーチ→記事/動画台本→監修Excel→修正反映）をそのまま中核に転用。
   - 「乳児の水分補給」「車内放置ゼロ」「夜間のエアコン設定」等を記事・YouTube・Shortsで週次配信し、全件に医師監修表記。
3. **受診目安ナビ（付帯機能）**
   - 症状チェックリストから「様子見／日中に受診／今すぐ救急」を提示。診断はせず、こどもの救急電話相談（#8000）・救急要請への導線に徹する。

### 4.3 AIの使いどころ（本事業の技術的優位性）

- **超局所リスク予測**: 広域のWBGT予報を、施設ごとの環境要因で補正するモデル。
- **文脈翻訳**: 同じリスク値を「園長向け運用指示」「保護者向けお知らせ」「こども向け紙芝居調」に多層生成 — 生成AIが最も得意とする領域で、既存パイプラインの資産がそのまま効く。
- **監修ループの自動化**: 既存の `--revise`（監修Excel→自動反映）機構により、医師監修の品質を保ったままコンテンツを量産できる。これは競合のセンサー系企業には真似できない参入障壁。

### 4.4 ビジネスモデル

| 収益源 | 単価目安 | 備考 |
|---|---|---|
| 施設向けSaaS（園・学校） | 月額5,000〜15,000円/施設 | 自治体一括契約で単価逓減・数量確保 |
| 自治体パッケージ（B2G) | 年額100〜500万円/自治体 | こども家庭部局の熱中症予防事業として。補助金・交付金と親和 |
| 保護者向けコンテンツ | 広告・タイアップ／将来的にプレミアム課金 | YouTube/記事は既存事業の延長 |
| 企業スポンサー | 飲料・空調・保険会社の協賛 | 商品名を出さない編集方針と両立する枠組みを設計 |

### 4.5 12か月ロードマップ

| フェーズ | 期間 | 内容 |
|---|---|---|
| Phase 0: 検証 | 〜2026-09 | 既存システムで熱中症テーマのコンテンツを集中生成・配信し、反応データを取得。近隣の保育園2〜3園でリスクブリーフの紙運用テスト |
| Phase 1: MVP | 2026-10〜2027-03 | 毎朝ブリーフ自動配信（LINE公式アカウント）＋監修コンテンツ配信を統合したβ版。オフシーズンに自治体・園への営業と補助金申請支援の準備 |
| Phase 2: 商用化 | 2027-04〜07 | 2027年夏に向け有償プラン開始。10自治体・100施設を初年度目標 |

### 4.6 リスクと対応

| リスク | 対応 |
|---|---|
| 医療的助言の責任問題 | 「診断・処方はしない／受診勧奨に限定」の既存編集方針を全機能に適用。免責表示と監修体制を明示 |
| 判断誤りによる事故（活動可の日に発症等） | 提示は常に「保守側」に倒す設計。最終判断は施設側にある旨を契約・UIで明確化。損害賠償保険の付保 |
| 季節性（夏季偏重） | 冬の感染症・乾燥対策など既存小児科コンテンツ事業と束ねて通年サービス化 |
| 大手（気象会社・センサー企業）の参入 | 「小児科医監修×現場の言葉への翻訳」に集中し、センサー企業とは競合でなく連携（データ入力元）と位置づける |

## 5. 次点案の展開余地

- **案2（企業向け教育SaaS）**: 義務化直後で需要が最も熱いが、産業医ネットワークの新規構築が必要。案1のコンテンツエンジンを業種別テンプレートに横展開する「第2の柱」として2027年度に検討。
- **案3（高齢者AI見守りコール）**: 社会的インパクト最大。自治体実証事業（補助金活用）として案1の自治体チャネルに相乗りする形が現実的。
