## 1. エグゼクティブサマリー

**事業内容:** 戦傷医療・災害医療に共通するボトルネックである「モノ(血液・衛生資材)とヒト(傷病者)のロジスティクス」を解決するプラットフォームを提供する。

- **第一プロダクト「BLOOD LINK(仮称)」:** 血液製剤・戦傷/災害医療資材のトレーサビリティ・在庫/鮮度管理・コールドチェーン監視・需給マッチングSaaS+IoT
- **第二プロダクト「TRIAGE LINK(仮称)」:** 有事・多数傷病者事案(MCI)・国民保護に特化した傷病者トラッキングと後送オーケストレーション(衛生指揮統制)

**コア市場:** 災害拠点病院の輸血部門・日赤血液センター・DMAT・都道府県(災害医療・国民保護)。**アンカー顧客:** 自衛隊衛生(自律的血液供給体制・南西後送体制)。**長期市場:** 米国・同盟国の軍事医療市場。

**なぜこの設計か(検証済みの根拠):**
1. **防衛衛生予算の最大の塊は「血液」に付いている【検証済】。** 令和7年度防衛予算は衛生機能強化の筆頭に「自律的な血液供給」(概算67億円規模※一次資料での金額確定は要フォロー)を計上。出血死の抑止・全血液型対応製剤の確保が国家防衛戦略上の課題として明記されている
2. **傷病者情報SaaSのカテゴリは米国で成功が証明済み【検証済】。** 米空軍BATDOKは2019年に実運用配備されJOMIS経由で全軍展開。スタートアップのT6 Health Systems(2014年ボストン創業)は民生救急医療ソフトを軍転用し、2025年にDHAと2030年までの複数年契約を締結、艦上での実配備段階にある
3. **一方、日本の平時救急SaaS市場は既にTXP Medicalが先行【検証済】。** 沖縄南部(県人口比32%)・山形県村山地域(50%超)・仙台市全市・東京消防庁で面展開済み。よって当社は**平時救急の記録層を避け、TXPが手薄な「血液・資材のモノの流れ」と「有事・MCIの指揮統制/後送層」を取る**
4. **規制の入口は軽い【検証済】。** 医療・健康情報の保存・管理・表示にとどまるプログラムは薬機法上の医療機器非該当(該当性ガイドライン明記)。AIによる診断支援に踏み込む機能のみフェーズ2でSaMD承認を取得する二段構え

**戦略の骨子:** 「規制の軽いレイヤーから入り、金の重いレイヤーに登る」
- フェーズ1(0〜2年):災害輸血・広域血液融通(民間)で有償実績、装備庁・SBIR等の公的R&Dで有事機能を開発
- フェーズ2(2〜4年):自衛隊の自律的血液供給体制の情報基盤へ、第二プロダクト(後送オーケストレーション)を重ねる
- フェーズ3(4年〜):米国法人スキームまたは現地提携による米国・同盟国市場参入(※日本資本のままの米SBIR直接応募は不可【検証済】)

**5年後の目標【仮置き】:** ARR 12億円、自衛隊血液ロジの正式調達実績、米国市場参入の足場確立。

**調達計画【仮置き】:** シード 1.5億円 → シリーズA 6億円(Y2) → シリーズB 20億円(Y4)。公的R&D資金を累計5億円規模で獲得(総資金の5割以内を規律とする)。

## 2. ビジョン・ミッション

- **ビジョン:** 「防ぎ得た死(Preventable Death)」を、平時・災害時・有事のすべてでゼロに近づける。
- **ミッション:** 極限環境における「血液・資材・傷病者」の流れの断絶をなくし、最適な医療資源配分を実現するロジスティクスOSを提供する。
- **ポジショニング原則:** 当社は「救急・災害・極限環境医療のロジスティクスの会社」であり、防衛は重要な顧客セグメントの一つ。「防衛スタートアップ」と自己定義しない(採用・調達・共同研究上の戦略判断)。

## 3. 解決する課題

### 3.1 モノの課題:血液・衛生資材(第一プロダクトの対象)

戦闘死・災害死の主因は出血であり、血液は「賞味期限のある、代替不能な、需要が突発する」最難度のロジスティクス対象である。

1. **有事:** 自衛隊は出血死抑止のため血液製剤を自律的に確保・備蓄する体制構築を進めている【検証済:国家防衛戦略・有識者検討会・令和7年度予算】。しかし在庫・鮮度・所在・後送先を一元的に追跡する情報基盤は未整備であり、南西島嶼への前方備蓄・洋上運用では鮮度管理と需給マッチングが死活問題となる
2. **災害時:** 広域災害では被災地の血液需要が急増する一方、献血・製造・供給網も同時に被災する。病院間・血液センター間の在庫融通は電話・FAXベースで、リアルタイムの需給可視化が存在しない
3. **平時:** 血液製剤の廃棄(期限切れ)と偏在は恒常的課題であり、離島・へき地へのコールドチェーン輸送の品質保証も脆弱
4. 止血材・凍結乾燥血漿・医療用酸素など**戦傷/災害医療資材全般に同じ構造の課題**が存在する

### 3.2 ヒトの課題:傷病者の後送(第二プロダクトの対象)

1. 南西方面有事では多数戦傷者の洋上・島嶼からの後送における傷病者追跡・優先度管理・後送手段割当が最大のボトルネック【検証済:国家防衛戦略は第一線から後送病院までのシームレスな医療・後送態勢の構築を課題として明記】
2. 国民保護事態・大規模災害では、自衛隊・消防・海保・DMAT・災害拠点病院の医療リソースを統合運用する情報基盤が存在しない
3. 米軍はBATDOK・T6(OpMed CDP)で同課題のシステム化を完了しつつあり【検証済】、日米共同作戦上の相互運用ギャップが顕在化しつつある

### 3.3 両者に共通する本質

「賞味期限・重症度という**時間制約のあるモノとヒトを、通信が途絶し得る極限環境で追跡し、限られた輸送・医療資源と動的にマッチングする**」という課題は、血液ロジと傷病者後送で同型である。同一の技術基盤(オフラインファースト同期・資源マッチングエンジン)で両プロダクトを構築できることが、本事業のアーキテクチャ上の核心である。

## 4. プロダクト

### 4.1 第一プロダクト:BLOOD LINK — 血液・衛生資材ロジスティクスSaaS+IoT

| モジュール | 機能 | 主要ユーザー |
|---|---|---|
| ① トレーサビリティ | 製剤単位のID管理(採血〜輸血/廃棄まで)、ロット追跡、使用記録 | 病院輸血部・血液センター・衛生科部隊 |
| ② 在庫・鮮度管理 | 期限アラート、血液型別在庫の可視化、廃棄率分析 | 同上 |
| ③ コールドチェーン監視 | IoT温度ロガー連携、輸送中の品質保証、逸脱アラート | 輸送事業者・離島搬送・後送部隊 |
| ④ 需給マッチング | 災害・有事時の広域在庫融通、需要予測、搬送手段割当 | 都道府県・血液センター・統合任務部隊 |
| ⑤ 訓練・演習モード | 広域輸血演習・国民保護訓練での模擬運用と事後検証 | DMAT・自衛隊・自治体 |

- **規制上の位置づけ:** 情報の記録・管理・表示・搬送支援に限定し**医療機器非該当**として設計【検証済:該当性ガイドラインの非該当類型に整合。該非事前相談で確定させる】。IoT温度ロガーは計測機器としての規格対応のみ
- **拡張:** 同一基盤で止血材・凍結乾燥血漿・酸素・医薬品へ横展開し「戦傷/災害医療資材のロジスティクスOS」へ

### 4.2 第二プロダクト:TRIAGE LINK — 有事・MCI特化の傷病者トラッキング/後送オーケストレーション

- NFC/QRタグ+モバイルによる傷病者登録・トリアージ記録・位置追跡、現場指揮ダッシュボード、**後送手段(ヘリ・艦艇・統合機動衛生ユニット・車両)との動的マッチング**
- **平時救急(消防の日常搬送)は対象としない。** TXP MedicalのNSER mobile等の平時救急システムとは競合ではなく**連接**する設計(平時データの受け口)とし、当社はMCI・災害・国民保護・有事の指揮統制層に特化する
- BLOOD LINKの需給マッチングエンジンと後送オーケストレーションは同一コア。血液という「初期市場が明確なモノ」で鍛えたエンジンをヒトに適用する順序を取る

### 4.3 技術的差別化

1. **通信途絶耐性(オフラインファースト・メッシュ同期):** 災害・有事の必須要件かつ、平時向けSaaSが最も作り込めていない領域。防衛市場への最重要の技術ブリッジ
2. **時間制約付き資源マッチングエンジン:** 期限のある製剤と重症度の高い傷病者を、動的に変化する輸送手段・受入能力に割り当てる最適化技術。両プロダクト共通のコア資産
3. **「訓練=実運用」の同一システム設計:** 毎年確実に予算がつく訓練市場を収益とデータ蓄積の両面で活用
4. **AI需要予測・重症度予測(フェーズ2以降):** 診断支援に該当する機能はSaMD(クラスII想定)承認を取得の上で段階投入

## 7. Go-to-Market戦略

### フェーズ1(Y1〜Y2):血液ロジの民間ビーチヘッド

1. **初期顧客:** 輸血使用量の多い災害拠点病院3〜5施設の輸血部門で、平時の在庫・期限・廃棄管理の効率化からPoC→有償化。**平時業務で毎日使われることが、災害・有事で機能する唯一の道**
2. **日赤との関係構築を最優先課題とする。** 血液供給は日赤の独占領域であり、競合ではなく「日赤の供給網を災害・有事に強くする情報基盤」としての共同事業ポジションを取る。学会(日本輸血・細胞治療学会、日本災害医学会)での共同研究・発表を通じKOLの支持を獲得
3. **広域輸血演習・国民保護訓練への訓練モード提供**から自治体・DMAT市場に入る
4. 並行して**装備庁 安全保障技術研究推進制度(SBIR指定)【検証済】**・SBIR・K Programに応募し、通信途絶環境・前方備蓄・洋上運用向け機能を公的資金で開発

### フェーズ2(Y2〜Y4):防衛アンカー顧客の獲得

1. 自衛隊の**自律的血液供給体制**【検証済:予算計上済み】の情報基盤として、自衛隊中央病院・防衛医大・衛生学校との共同研究→統合演習での試験運用→部隊使用の実績化
2. 血液で信頼を得た後、**第二プロダクト(傷病者後送オーケストレーション)**を統合演習・国民保護共同訓練に投入。「モノの流れ」と「ヒトの流れ」を同一基盤で束ねる価値を実証
3. セキュリティクリアランス(適性評価)対応・ISMAP取得・情報管理体制を整備

### フェーズ3(Y4〜):米国・同盟国展開(v0.2で経路を修正)

**v0.1の「米SBIR経由の参入」は撤回する。** 米DoD SBIRは51%以上を米国市民/永住者が保有・支配することが必須要件であり、審査で実質所有者まで遡って厳格に確認される【検証済】。修正後の経路:

1. **経路a(本命):米国子会社を設立し、米国資本・米国人経営陣が過半を握るスキームを設計**した上でSBIR・OTA契約に応募(法務・資本設計の専門家関与が前提。要件充足の可否自体を事前に法務確認)
2. **経路b:米国プレイヤーとの提携。** T6 Health Systems等との相互補完(当社=同盟国側の実装・日米連接)や、米国側パートナー経由でのDHA納入
3. **経路c:同盟国連接ルート。** BATDOKは英・豪等の同盟国軍も試験しており【検証済】、日米共同演習における衛生システム連接の実績を「相互運用可能な同盟国製品」としての信用材料にする
4. 人道支援・災害救援(HA/DR)文脈での国際機関・NGO市場も並行探索

## 11. リスクと対応策(v0.2で改訂)

| リスク | 影響 | 対応策 |
|---|---|---|
| **日赤エコシステムに入れない** | **致命的** | 競合ではなく供給網強化のパートナーとしての設計を徹底。輸血専門医を創業チームに置き、学会経由で信頼構築。入れない場合のプランB(病院側・自衛隊側からの挟み撃ち)も維持 |
| **TXP Medicalの領域拡張(有事・血液への進出)** | 高 | 血液ドメインの専門性・防衛ネットワークで先行し、連接APIで相互依存関係を作る。訓練・演習市場の実績を先に押さえる |
| 官公庁販売サイクルによる資金枯渇 | 高 | 平時の病院輸血業務という「毎日使われる」収益基盤を先に確立。ランウェイ24ヶ月以上を常時維持 |
| 防衛予算の政策転換 | 中 | 民間売上のみで存続可能な損益構造(防衛比率は売上の50%を上限目安) |
| 米国参入スキームの法的不成立 | 中 | フェーズ3着手前に米国法務DD。経路b(提携)・c(同盟国連接)を並行維持し単一経路に依存しない |
| 医療界・アカデミアの防衛忌避 | 中 | 「災害医療ロジスティクスの会社」としてのポジショニング徹底、HA/DR実績の先行蓄積 |
| SaMD規制によるAI機能遅延 | 低〜中 | 非該当機能のみで成立する事業構造を維持(該当性ガイドラインの非該当類型に整合【検証済】) |
| 情報セキュリティ事故 | 高 | 要配慮個人情報前提のセキュリティ・バイ・デザイン、第三者監査、サイバー保険 |
| キーパーソン(輸血専門医・衛生OB)不在/離脱 | **致命的** | 創業株式・SOによるリテンション、顧問ネットワークによる冗長化。**組成できるまで法人設立・調達を先行させない** |

## 12. Exit戦略・長期構想

- **主シナリオ:IPO(Y7〜Y9)。** 官公庁・防衛向け事業の継続性・信用力は上場と親和的
- **副シナリオ:戦略的M&A。** 国内大手SIer・医療機器/物流大手・海外防衛IT(T6等の米国プレイヤーを含む)。防衛関連事業を含むため外資への売却は外為法審査を前提に選択肢を管理
- 長期構想:血液→衛生資材→傷病者後送と広げ、「戦傷・災害医療のロジスティクスOS」として、遠隔医療統合・後送手段オーケストレーション・日米衛生連接まで拡張する
