# 握るグリップ型アクティブ温調パームクーラー 要件定義(v0.1)

競合調査(palm-cooler-competitive-analysis.md)で特定した空白「¥1〜3万のアクティブ温調・日常シーン特化」を突くプロダクトの要件定義。
仮称: **GRIP COOLER(グリップクーラー)**

---

## 1. コンセプト

> **「握るだけで、深部体温が下がる」— 15℃を一日中キープする、通勤のための携帯ラジエーター。**

- PCM式(コアクーラー、IceBattery)の弱点 = **溶けたら終わり・再凍結が必要** を、ペルチェ制御で「常に適温」に置き換える。
- ペルチェ式ハンディファンの弱点 = **冷たすぎて血管収縮(深部冷却に逆効果)** を、「科学的適温12〜15℃の恒温制御」で置き換える。
- グローブ型(既存の主流)ではなく**グリップ(握り棒)型**: 通勤・通学で違和感なく、着脱ゼロ、片手で使える。

### ポジショニング一行
「ハンディファンの次に買う、"体の中から冷える"ガジェット」

## 2. ターゲット・利用シーン

| 優先 | ペルソナ | シーン | 要求 |
|---|---|---|---|
| P0 | 都市部通勤者(25〜45歳) | 駅まで徒歩+ホーム待ち(往復40〜60分) | 汗だく出社の回避。カバンに入る、持って恥ずかしくない |
| P0 | 中高生・部活保護者 | 通学、観戦、部活の合間 | 安全性、価格、落下耐性 |
| P1 | ランナー・ゴルファー | 運動中・ラウンド間 | 軽さ、滑らない、汗濡れ対応 |
| P2 | 現場作業者(B2B) | 休憩時間の急速クールダウン | 法改正対応、複数台管理、堅牢性 |

## 3. 熱設計の成立性(最重要検討)

商品化可否を決めるのはここ。先に数字を置く。

- 接触面積: 手のひら(グリップ把持時)約 **50〜80cm²**
- 手掌からの熱引き抜き量: 手掌冷却研究ベースで **15〜30W 程度**を目標(AVA開通時)
- 動作条件: 外気35℃で冷却面15℃(ΔT=20K)を維持
- ペルチェ所要電力: COP≈1前提で **消費 15〜25W**、排熱側は 30〜55W → **小型ファン+ヒートシンク必須**(自然放熱では不可)
- 電池: 10,000mAh/3.7V=37Wh → 連続フル駆動で **約1.5〜2時間**

### 成立させる3つの設計判断
1. **パルス駆動を標準モードにする**(アイディア2-1の知見): 冷却30秒/休止30秒等の周期駆動。温度感受性は変化量に敏感なため体感を保ったまま消費電力を約半分に → **実用3〜4時間**。
2. **「連続深冷モード」は短時間ブースト扱い**: ホーム待ち・信号待ちの5〜10分で深部体温を下げる使い方を訴求(手掌冷却は10分程度でも深部体温に効くというエビデンスと整合)。
3. **ハイブリッド蓄冷**: グリップ芯に少量のPCM(15℃帯)を内蔵し、ペルチェは「PCMの再凍結役」を兼ねる。ピーク電力を平準化し、電源オフ後も10〜15分は冷たさが残る。

## 4. 製品要件

### 4.1 ハードウェア(MVP=P0)

| 項目 | 要件 | 根拠 |
|---|---|---|
| 形態 | 円筒グリップ型(径35〜40mm×長さ130〜150mm)、缶コーヒー程度 | 把持時にAVA密集部(手のひら中央〜指基部)へ冷却面が当たる |
| 冷却面温度 | **12〜15℃恒温制御**(サーミスタ+PID)。10℃未満にならないハード保護 | 血管収縮の閾値回避=カテゴリの科学的差別化そのもの |
| 冷却方式 | ペルチェ1〜2素子+グリップ芯PCM(15℃帯)ハイブリッド | §3 |
| 駆動モード | ①パルス(標準、3〜4h) ②連続ブースト(10分タイマー) ③PCMのみ(電源オフでも可) | 通勤往復+日中をカバー |
| 排熱 | 軸流ファン+フィン、排気は上方(顔・服に当てない)。騒音≦35dB(電車内許容) | 排熱30〜55W |
| 電池 | 10,000mAh、USB-C(PD対応)、**モバイルバッテリー兼用(給電出力可)** | 「夏以外も使える」で購入正当化。ハンディファン市場の定石 |
| 重量 | **≦350g**(目標300g) | ハンディファン上位機と同等 |
| 耐環境 | IPX4(汗・小雨)、1.2m落下耐性、45℃環境動作 | 屋外日常使用 |
| 安全 | 低温やけど防止(冷却面は12℃下限)、排熱面≦48℃、PSE適合電池、過熱時自動停止 | 雑貨として販売するための必須条件 |
| 色・意匠 | 「冷却ガジェット」ではなく水筒・オーディオ系の落ち着いた意匠 | 通勤で持って恥ずかしくない=P0要求 |

### 4.2 ソフトウェア(段階導入)

- **MVPはアプリ非必須**(本体ボタン+LEDのみで完結)。
- P1: BLE+アプリ = 温度ログ、「深部体温クールダウン完了」推定通知、パルスパターンのカスタム。
- P2(B2B): 管理ダッシュボード(装着ログ×WBGT連動、労安法改正対応レポート)。

### 4.3 やらないこと(スコープ外)

- 医療機器認証(MVPでは雑貨。効果効能の広告表現は景表法レンジで設計。医療機器化はCOLDWRAP PALMの後追いになるため P2 で再検討)
- 加温(冬モード)— 将来のライン拡張候補として設計上の余地だけ残す(ペルチェは極性反転で加温可能)
- グローブ型・装着型バリエーション

競合との位置: コアクーラー¥3,960(パッシブ) ≪ **本製品¥14,800** ≪ CoolMitt $1,000。ネッククーラー(REON等¥1〜2万)と同価格帯であり「首より手のひらの方が深部に効く」が正面の訴求軸。

## 6. 検証計画(要件の裏取り)

1. **熱ベンチ**: ペルチェ+フィン試作で35℃環境・把持状態の15℃維持と消費電力を実測(§3の仮説検証。ここが崩れたら形態を再検討)
2. **生理効果**: 被験者10名で運動後の深部体温(耳内/カプセル)回復速度を、本試作 vs コアクーラー vs 何もなし で比較
3. **受容性**: 通勤者20名に2週間貸与、使用継続率・持ち歩き率・「恥ずかしさ」ヒアリング
4. **FTO**: 真空方式(AVAcore)・グローブ構造(Louisville)・シャープPCMの特許回避確認(グリップ+ペルチェ+PID恒温は既存特許と方式が異なる想定だが要専門調査)

## 7. リスクと対応

| リスク | 影響 | 対応 |
|---|---|---|
| 排熱が手や体に当たり「逆に暑い」 | 体験の根幹 | 排気方向の人間工学設計を最優先。試作で官能評価 |
| 電池持ちが訴求に届かない | 「一日中」が嘘になる | パルス標準+PCMハイブリッド。訴求は「往復通勤+ブースト数回」と正直に |
| 「保冷剤で十分」という価格抵抗 | 売価¥14,800の壁 | 「再凍結不要・常に適温・モバ充兼用」の3点で正当化。B2Bで数を作る |
| 大手(シャープ/デサント)のアクティブ化参入 | 競合直撃 | 先行でグリップ型の意匠・商標・体験データを固める。パルス制御ノウハウを特許出願 |
| 猛暑日以外は売れない季節商材リスク | 事業性 | モバ充兼用+冬の加温モード(P2)で年間商材化 |
