# business/ — 会社の頭脳（経営ドキュメント一式）

ここは、AIと人間が一緒に会社を経営するための**共有された頭脳**です。
迷ったらここに戻ってくれば、私たちが何を・なぜ・どうやろうとしているかが分かります。

> ミッション: **子育てに奔走するママに、安らぎと安心を。
> 心配・不安・苦悩から解放し、「子育ては喜び」だと思い出してもらう。**

## 使い方
1. 新しいことを始める前に、関連ドキュメントを読む
2. 大きな分岐を決めたら `decisions/` に残す
3. 週に一度 `meetings/` で振り返り、`05_roadmap.md` の「次の一手」を更新する
