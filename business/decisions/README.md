# decisions/ — 意思決定の記録（ADR）

重要な分岐を「あとから理由を辿れる」形で残す場所です。
1決定 = 1ファイル（`NNNN-短いタイトル.md`）。

## 書き方（テンプレ）
```
# ADR NNNN: タイトル
- 日付 / ステータス（提案中・採用・破棄・置き換え）/ 決めた人
## 背景    … なぜ決める必要があったか
## 選択肢  … 検討した案
## 決定    … 何に決めたか
## 理由    … なぜそれにしたか
## 影響    … 何に波及するか
```
