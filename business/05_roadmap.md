## フェーズ計画

### フェーズ0：土台（今ここ）
- [x] 事業の方向性決定（赤ちゃん睡眠アプリ／SIDS不安からの解放）
- [x] 経営ドキュメント一式（`business/`）と AI共同経営の憲法（`CLAUDE.md`）
- [ ] OK/NGワード集（安全コピー指針）
- [ ] ブランド名の最終決定

### フェーズ1：課題検証（Problem/Solution Fit）
- [ ] ママ5〜10人へのインタビュー（夜の不安は本物か／何に一番困るか）
- [ ] LPプロトタイプ＋待機リスト登録で「価値仮説」を検証
- [ ] 集客コンテンツを数本公開し、検索/SNSの反応を見る
- **ゲート**: 「夜の不安」と「監視しない安心アプリ」への共感が確認できたら次へ

### フェーズ2：MVP（Product/Market Fit の入口）
- [ ] コア機能の最小実装（ナイトルーティン／安全セルフチェック／よりそいトーク）
- [ ] toto先生監修を通したコンテンツを搭載
- [ ] [04](04_safety_ethics.md) のリリース前必須ゲートを全通過
- [ ] 限定ユーザーへのクローズドβ
- **ゲート**: 継続利用と「夜が楽になった」の声が一定数出たら次へ

### フェーズ3：グロース
- [ ] 課金（サブスク）導入と価格検証（[07](07_revenue_model.md)）
- [ ] コンテンツ・エンジンで集客を仕組み化
- [ ] リテンション改善（安心の体験を磨く）

### フェーズ4：拡張
- [ ] 0〜1歳の他の不安テーマ（発熱・離乳食・発達）へ横展開
- [ ] ママのメンタルケアへの広がり
