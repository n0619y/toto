# データ分析の結論と戦略設計（GoldVBO）

データ: XAUUSD H1/D1, 2012-05〜2022-03（公開データ ejtraderLabs）。
※出所・タイムゾーン不明・2022年で停止 → **本戦略は時刻に非依存に設計**し、
最終確認はXM実データで行う前提。

---

## 1. データから分かった「頑健な事実」

| 観測 | 数値 | 含意 |
|------|------|------|
| 日次方向の自己相関 | ≈0（lag1 +0.013） | **方向は予測困難** → 単純な方向系は勝てない |
| 分散比 VR(20) | 0.93（<1） | 長期は弱い平均回帰 → 乗りすぎ厳禁 |
| ボラの自己相関(|ret|) | lag5 +0.11 | **ボラはクラスタリング（最も再現性ある手がかり）** |
| 尖度 | 7.0 | ファットテール → 急変が多い → **ハード損切り必須** |
| 歪度 | -0.60 | 下落が急 → リスク連動サイズが重要 |
| ATR/価格 中央値 | 1.24% | SL/TP・ロット計算の基準 |

実際、ナイーブな常時建玉戦略（MAクロス/日次平均回帰/Donchian）は**いずれも優位性なし〜マイナス**だった。
→ 「方向当て」ではなく「**ボラ拡大の初動に乗り、トレンドに逆らわず、損切りを固める**」方針へ。

---

## 2. 戦略 GoldVBO（Volatility Breakout）

| 要素 | 内容 | 根拠 |
|------|------|------|
| エントリー | 直近Nバー高値/安値のブレイク（**時刻非依存**） | 初動を取る／時差不明問題を回避 |
| トレンドフィルタ | EMA200の上のみ買い・下のみ売り | OOSでPF/DD改善を確認 |
| ボラゲート | ATR>直近200本ATR中央値の時のみ参加 | ボラ・クラスタリングの利用 |
| 損切り | エントリー∓ ATR×2.0（ハード） | ファットテール対策 |
| 利伸ばし | ATR×3.0 チャンデリア・トレーリング | 平均回帰を避け利を伸ばす |
| 時間切れ | 72本で手仕舞い | 滞留・オーバーナイト過多の抑制 |
| サイズ | リスク1%でロット自動計算 | 下方歪み対策（ボラ連動） |

## 3. 検証結果（過剰最適化を避けた手順）

**手順:** In-Sample(2012-2018, 前半60%)で「ブレイク幅」だけ粗くスキャン→1つ選定→
**Out-of-Sample(2018-2022, 未最適化)で評価**。

### OOS 本番（IS最良 BO=12, コスト$0.5/往復）
- **CAGR +17%、PF 1.27、最大DD -12.7%、652トレード、勝率42%**
- Buy&Holdより高リターンかつ低ドローダウン（OOS期間）

### 過剰最適化でない根拠
- **パラメータ安定性**: ブレイク幅12〜120の**全設定がOOSで黒字**（PF 1.29〜1.51）
- **SL/トレール近傍**: 9通り全て黒字（PF 1.16〜1.34）= 面で勝つ
- **アブレーション**: トレンドフィルタ除去→PF1.29→1.09・DD倍増／ボラゲート除去→PF→1.12
  （＝データ分析で立てた両仮説がOOSで価値を持つと確認）

### コスト感応度（最重要）
| 往復スプレッド | PF |
|----------------|----|
| $0.20 | 1.34 |
| $0.35 | 1.29 |
| $0.50 | 1.27 |
| $0.80 | 1.11 |
| **$1.20** | **0.95（損益分岐）** |

→ XMの通常スプレッド($0.2〜0.5)では十分なマージン。**ただし$1.2付近で優位性が消える**。
**低スプレッド口座＋スプレッドフィルタ必須**。ニュース時は要注意。

## 4. 正直な限界（必ず認識すること）

- 単一データ源・2012-2022・**XMではない**・**2022-2026未検証**。
- H1足の約定は近似（高速変動時のスベリは実際にはより悪い可能性）。
- 1銘柄のみ。レジーム変化で劣化しうる。
