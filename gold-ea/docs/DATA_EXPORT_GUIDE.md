# XM の MT4 から信頼できるヒストリカルデータを出す手順

目的: **EAが実際に動くのと同じ環境（XM・同じサーバー時間）**のゴールドデータを取得し、
素性・タイムゾーン・鮮度の問題を解消する。前回の拾い物データ（素性/時差不明・2022年で停止）
の問題をここで潰す。

---

## ステップ1: できるだけ多くの履歴をMT4に読み込ませる

1. **[ツール] → [オプション] → [チャート]** タブ
   - 「ヒストリー内の最大バー数」「チャートの最大バー数」を **大きな値**（例 `99999999`）にする。
2. XMのMT4で **GOLD** のチャートを開く。
3. 取得したい時間足を選ぶ（**まずは H1 を推奨**。日中分析用に M15 もあると良い）。
4. チャート左端で **Home キーを連打** or 左へスクロールし、過去データを読み込む。
   - 足りない場合は **[ツール] → [ヒストリーセンター] (F2)** で GOLD を選び各時間足を
     ダウンロードしてからチャートを開く。

> ヒント: H1 なら数年〜10年、M15 なら直近数年あれば十分です。

---

## ステップ2: エクスポートスクリプトを配置・コンパイル

1. MT4 **[ファイル] → [データフォルダを開く]** → `MQL4/Scripts/` に
   `gold-ea/scripts/ExportHistoryCSV.mq4` をコピー。
2. MetaEditor で開いて **コンパイル**（エラー0）。
3. MT4を再起動 or ナビゲータ更新で「スクリプト」に `ExportHistoryCSV` が出る。

---

## ステップ3: 実行してCSVを書き出す

1. データを読み込ませた **GOLD のチャート**に `ExportHistoryCSV` を**ドラッグ＆ドロップ**。
2. パラメータ `ExportBars` は **0（全件）**のままでOK。実行。
3. 完了アラートが出る。ファイルは **`MQL4/Files/GOLD_60min_export.csv`** のような名前で生成。
   - 60min = H1。M15 なら 15min。
4. 必要なら時間足を変えて（M15など）もう一度実行。

---

## ステップ4: CSVを私に渡す

`MQL4/Files/` 内のCSVを以下のどれかで共有してください:
- このセッションに添付
- リポジトリの `gold-ea/data/` に置いてパスを教える
- Google Drive に置いてファイル名を教える（こちらで読みます）

### CSVの中身（私が読む形式）
```
#META, symbol=GOLD, tf_min=60, digits=2, server_gmt_offset_hours=2, exported_server_time=2026.06.22 14:30
DateTime, Open, High, Low, Close, Volume
2014.01.02 01:00, 1203.50, 1205.10, 1202.80, 1204.90, 1234
...
```
1行目の `server_gmt_offset_hours` で**タイムゾーンを正しく補正**できます。これで
「セッション分析の時間が実運用とずれる」問題が解消します。

---

## 受け取ったら私がやること

1. METAでタイムゾーンを較正し、ロンドン/NYセッションを**正しい時刻**で再分析。
2. 鮮度のあるデータ（2022以降も含む）で統計的性質を再確認。
3. その上で、**過剰最適化を避けた頑健なEA設計**と**ウォークフォワード検証**へ進む。
