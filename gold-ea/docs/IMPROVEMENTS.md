# EA改善ラボ：体系的な改善探索の記録

`backtest/lab.py` で改善案を片っ端から高速検証した記録。

## 評価規律（過剰最適化を排除）
- **チューニング = 公開データ2012-2022**（2018チョップ・2013暴落を含む全レジーム）
- **XM実データ2023-2025 = 完全ホールドアウト**（確認専用、ここでは最適化しない）
- **両データで改善した案のみ採用**

## ベースライン
H1: bo12, ER0.30, EMA200, SL2.0, Trail3.0, maxhold72
→ 公開OOS PF2.22/DD-5.6%/Sharpe2.35, XM PF2.37/DD-5.2%/Sharpe2.72

## 検証した案と結果

| 案 | 結果 | 採否 |
|---|---|---|
| SL_atr 1.5〜3.0 | 2.0が均衡(小はPF↑DD↑) | 据え置き |
| **Trail_atr 2.0〜5.0** | **2.5が両データでSharpe改善** | ✅採用 |
| maxhold 48〜∞ | 効果なし(トレール支配) | 据え置き72 |
| ER閾値 0.20〜0.40 | 0.30が均衡 | 据え置き |
| ER期間 10〜30 | 15はXM特化(公開で劣化)=過剰最適化 | 据え置き20 |
| ADXフィルタ | ER以上の効果なし、XMで劣化 | 不採用 |
| ブレイク・バッファ | 全て劣化 | 不採用 |
| EMA200 ON/OFF | ONが明確に良い | 据え置きON |
| ブレイクイーブン・ストップ | 早すぎる損切で劣化 | 不採用 |
| トレール発動遅延 | 改善なし | 不採用 |
| **部分利確(+3ATRで50%→残りトレール)** | **両データでSharpe激変** | ✅採用 |

## 採用した最終構成（GoldVBO v2）
ベースライン + **Trail 3.0→2.5** + **部分利確(TP1=3.0ATR, 50%利確, 残りは建値+トレール)**

### 効果（baseline → v2）
| 指標 | 公開2012-22(全期間) | XM 2023-25 |
|---|---|---|
| Sharpe | 2.41 → **3.22** | 2.72 → **3.72** |
| 最大DD | -10.5% → **-6.2%** | -5.2% → -5.7% |
| PF | 2.14 → 2.19 | 2.37 → 2.25 |
| 勝率 | — → **67%** | — → 66% |

### 年別（公開）— 弱点だったチョップ年が黒字化
| 年 | baseline | v2 |
|---|---|---|
| 2018(チョップ) | -2.6% / DD-10.5% | **+9.8% / DD-6.2%** |
| 他の年 | — | ほぼ全年で改善 |

## なぜ部分利確がこれほど効くか
半分を+3ATRで確定 → 利益の「戻し」を防ぎ**資産曲線が滑らか**に（リターン分散↓→Sharpe↑）。
残り半分は建値ストップ+トレールで**大トレンドも取りこぼさない**。
結果、総利益(PF)はほぼ維持したまま、DDと変動だけが縮小。**揉み合い相場で特に効く**
（早めに利を抜くため、だまし戻りの被害が減る）→ 2018年の黒字化。

## 注意
すべてPython理想約定の参考値。部分利確はMT4で逆指値ストップ＋OrderClose分割で実装済み
（建玉時刻を安定キーに二重利確を防止）。最終確認はMT4全ティック/デモで。
