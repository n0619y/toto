# Tickstoryで多年ティックデータを取り込み99%品質の全ティック検証

XMはM1を約2.5ヶ月しか配信しないため、多年の全ティック検証が不可。
**Tickstory(無料)でDukascopyのXAUUSDティックを取得→MT4に取り込み、99%品質で検証**する。

> 注意: Dukascopyの価格はXMと別フィード（金価格なのでほぼ同じだが完全一致ではない）。
> 「戦略ロジック＋実約定が多年・多レジームで通用するか」の検証には十分。最終のXM固有確認は
> デモ・フォワードで行う。

## 事前準備（推奨）
- バックテスト専用に**MT4をもう1つ別フォルダにインストール**すると安全
  （Tickstoryが履歴ファイルを書き換えるため、運用用と分けると事故がない）。
- 専用MT4にも GoldVBO.mq4 / include / preset を入れてコンパイルしておく。

## 手順

### 1. Tickstory Lite(無料)をインストール
- https://tickstory.com から Tickstory Lite をダウンロード→インストール（Windows）。

### 2. XAUUSDのティックデータをダウンロード
1. Tickstory左の「Data」ツリーで **Dukascopy → XAUUSD** を探す。
2. XAUUSDを右クリック →「Download to Cache」（または Update Symbol）。
3. 期間を指定（例: **2015.01.01〜現在**）。ティックは重いので時間がかかる（数十分〜）。

### 3. MetaTrader4へエクスポート
1. XAUUSDを右クリック →「**Export to...**」→ **MetaTrader**。
2. ウィザードで設定:
   - **MT4インストール先**: バックテスト用MT4のフォルダを指定
   - **マッピング先シンボル**: `GOLDmicro`（または専用シンボル名）
   - **期間(timeframe)**: M1（全ティック生成の土台。1分足を出す）
   - **日付範囲**: 2015〜現在
   - **スプレッド**: 35ポイント（=$0.35）など実態に近い固定値
3. 「Generate」/「Launch MetaTrader」。Tickstoryが .hst/.fxt を生成しMT4のテスターを開く。

### 4. MT4ストラテジーテスターで実行
- エキスパート: **GoldVBO**
- 通貨ペア: マッピングしたシンボル（GOLDmicro等）
- モデル: **全ティック（Every tick）**
- 期間(足): **H1**（EAはH1設計）
- 日付: 2015〜現在（または見たい範囲）
- [エキスパート設定]→[読込]で `GoldVBO_H1.set`
- **[スタート]**

### 5. 結果の確認（Pythonの予測と照合）
- **モデリング品質 99%** になっているはず（Tickstoryの効果）
- 期待値の目安（Python・XM2.3年）: **PF 2前後 / 最大DD 一桁% / Sharpe 高め**
  ※Dukascopyフィード・多年なので数値は完全一致しない。**PF>1.3かつDDが想定内なら合格**。
- [グラフ]で資産曲線が右肩上がり・部分利確でDDが浅いことを確認。

## つまずきやすい点
- エクスポート中はMT4を**閉じておく**（履歴ファイル競合回避）。
- シンボルのマッピングがずれると「データがない」エラー→ウィザードのシンボル名を確認。
- Tickstory無料版はMT4対応（MT5は有料のことがある）。
- 99%品質が出ない→M1が正しく生成/配置されていない。エクスポートのtimeframe=M1を確認。

## 判定後
- 多年・99%品質で **PFと最大DDがPython検証と整合** すれば、戦略は実約定でも通用する確度が高い。
- 次は**デモ・フォワード**でXM固有の挙動を最終確認 → 少額リアル。
