# 2戦略ポートフォリオ運用ガイド（GoldVBO + GoldTentei）

「資金が増える＋大きく溶けない」を狙い、**性質の異なる2戦略を同口座で併用**する。

## なぜ2戦略か（データ根拠）

2つはエントリーが正反対で**ほぼ無相関**（日次相関 +0.02）:
- **GoldVBO** … ブレイクで「強さを買う」（順張り初動）
- **GoldTentei** … 押し目で「弱さを買う」（トレンド内の押し目/戻り、**H4トレンド一致時のみ=MTF**）

> 天底は上位足H4のEMA(100)で大局を一致確認するMTFフィルタを追加し、
> 単体OOSが PF1.16→**1.42** / DD-9.4%→**-6.5%** / Sharpe0.24→**0.53** に強化された
> （詳細は `backtest/tentei_h1_v3.py`）。下表はこの改善版での再計測。

配分スキャン（OOS 2018-2022, コスト$0.5, VBO比率を変化）:

| VBO:Tentei | CAGR | 最大DD | Sharpe |
|---|---|---|---|
| 100:0 (VBO単体) | +19.1% | -11.9% | 1.13 |
| 70:30 | +14.6% | -9.1% | 1.21 |
| **60:40 (推奨)** | **+13.0%** | **-8.5%** | **1.23** |
| 50:50 | +11.5% | -7.8% | 1.25 |
| 30:70 | +8.4% | -7.0% | 1.17 |
| 0:100 (天底単体) | +3.6% | -6.5% | 0.53 |

**読み方:**
- Sharpe は **VBO 50〜70% でほぼ平坦**（1.21〜1.25, 配分はシビアでない）。
- VBO% を上げる＝CAGR↑/DD↑ の**リターン⇔リスクのダイヤル**。
- 天底のMTF強化で最適点が **VBO 50〜60%** へ移動（天底の貢献が増えた）。
- **推奨は 60:40**（Sharpe最良圏でCAGR+13%/DD-8.5%のバランス）。
  リターン重視なら70:30、DD最小重視なら50:50でもよい。

## 設定方法（同口座で併用）

両EAを**同じ GOLD H1 チャート**（または別チャート）に適用。
**マジックナンバーが別**（VBO=20260622 / Tentei=20260623）なので互いに干渉しない。

### 推奨リスク配分（合計で過大にしない）
- GoldVBO: `RiskPercent = 0.6`
- GoldTentei: `RiskPercent = 0.4`
（合計でも1トレード級のリスクが口座の1%程度に収まるイメージ。最初は控えめに。
 リターン重視なら 0.7/0.3、DD最小重視なら 0.5/0.5 でも可）

> GoldTentei は `UseMtfFilter=true`（既定）で H4 トレンド一致フィルタが有効。
> `PivotK=3` / `MtfEmaPeriod=100` が OOS 最良値（既定で設定済み）。

> 重要: 2つ同時に建玉する局面では合計リスクが増える。`MaxDailyLossPct` /
> `MaxDrawdownPct` は**両EAに設定**し、口座全体の安全装置として効かせる。

## 検証手順（必須）

1. `docs/DATA_EXPORT_GUIDE.md` で **XM実データ**を出力。
2. 各EAを**個別に**ストラテジーテスター（GOLD/H1）で検証し、KPI
   （PF>1.2, DD<20%）を確認。
3. デモ口座で**両EAを同時に**フォワードテスト（数週間）。
4. 問題なければ少額リアルへ。配分は結果を見て調整。

## 限界（再掲）
公開データ(2012-2022)の参考値。XM実データ・直近相場での再確認が前提。
2戦略でもレジーム変化で同時に劣化する局面はある。安全装置を必ず有効に。
