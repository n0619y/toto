# 2戦略ポートフォリオ運用ガイド（GoldVBO + GoldTentei）

「資金が増える＋大きく溶けない」を狙い、**性質の異なる2戦略を同口座で併用**する。

## なぜ2戦略か（データ根拠）

2つはエントリーが正反対で**ほぼ無相関**（日次相関 +0.02）:
- **GoldVBO** … ブレイクで「強さを買う」（順張り初動）
- **GoldTentei** … 押し目で「弱さを買う」（トレンド内の押し目/戻り、**H4トレンド一致時のみ=MTF**）

> GoldVBOは**v2(部分利確)で大幅強化**（単体Sharpe 3.2/3.7, 詳細`docs/IMPROVEMENTS.md`）。
> 天底はH4トレンドMTFフィルタ付き(`tentei_h1_v3.py`)。下表はこの最新版での再計測。
>
> 補足: 天底への部分利確の適用は検証したが**公開データで劣化**したため不採用
> （天底は構造的目標に到達するのが優位性で、VBOとは別archetype）。

配分スキャン（GoldVBO v2 + 天底, 日次リバランス, コスト$0.5）:

| VBO:Tentei | 公開2012-22 Sharpe/DD | XM2023-25 Sharpe/DD |
|---|---|---|
| 100:0 (VBO単体) | 3.22 / -6.2% | 3.72 / -5.3% |
| **70:30 (推奨)** | **3.14 / -5.1%** | **3.83 / -3.1%** |
| 60:40 | 3.04 / -4.8% | 3.77 / -2.8% |
| 50:50 | 2.85 / -4.5% | 3.60 / -2.5% |

**読み方（v2で構図が変化）:**
- VBO v2が非常に強くなったため、**天底は"リターンの足し"でなく"DD保険"**の役割に。
- 相関0.07〜0.10で、天底を混ぜると**DDが大きく縮小**（XM -5.3%→-3.1%）。
- VBOが強化された分、最適配分は **60:40→70:30 に上方修正**。
  Sharpeをほぼ保ちつつDDを削れる。リターン最優先ならVBO単体でも可、DD最小重視なら60:40。

## 設定方法（同口座で併用）

両EAを**同じ GOLD H1 チャート**（または別チャート）に適用。
**マジックナンバーが別**（VBO=20260622 / Tentei=20260623）なので互いに干渉しない。

### 推奨リスク配分（合計で過大にしない）
- GoldVBO: `RiskPercent = 0.7`（v2＝部分利確版が主力エンジン）
- GoldTentei: `RiskPercent = 0.3`（DD保険）
（合計でも1トレード級のリスクが口座の1%程度に収まるイメージ。最初は控えめに。
 DD最小重視なら 0.6/0.4、リターン最優先ならVBO単体でも可）

> GoldTentei は `UseMtfFilter=true`（既定）で H4 トレンド一致フィルタが有効。
> `PivotK=3` / `MtfEmaPeriod=100` が OOS 最良値（既定で設定済み）。

> 重要: 2つ同時に建玉する局面では合計リスクが増える。`MaxDailyLossPct` /
> `MaxDrawdownPct` は**両EAに設定**し、口座全体の安全装置として効かせる。

## 検証手順（必須）

1. `docs/DATA_EXPORT_GUIDE.md` で **XM実データ**を出力。
2. 各EAを**個別に**ストラテジーテスター（GOLD/H1）で検証し、KPI
   （PF>1.2, DD<20%）を確認。
3. デモ口座で**両EAを同時に**フォワードテスト（数週間）。
4. 問題なければ少額リアルへ。配分は結果を見て調整。

## 限界（再掲）
公開データ(2012-2022)の参考値。XM実データ・直近相場での再確認が前提。
2戦略でもレジーム変化で同時に劣化する局面はある。安全装置を必ず有効に。
