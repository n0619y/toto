# RobustDuo（MT4用EA）

性質の違う2つの戦略を1つのEAに載せ、口座全体でリスクを管理するEAです。
マーチンゲール、ナンピン、グリッドは使わず、全ポジションに損切りを置きます。

> **未検証です。** このコードはMetaEditorでのコンパイルもバックテストもまだ行っていません。
> 既定パラメータは出発点であり、利益を保証するものではありません。
> 下の「検証手順」を通過するまで、実資金では動かさないでください。

## 導入

1. `RobustDuo.mq4` を MT4 の `MQL4/Experts/` に置き、MetaEditorでコンパイルします。
2. EURUSD、USDJPY、GBPUSD、XAUUSD のチャートを1枚ずつ開き、それぞれにEAをセットします。
   チャートの時間足は何でも構いません（EAは内部でH1とH4を参照します）。
3. `MagicBase` は4枚とも同じ値にします。口座全体の制限はこの値で共有されます。
4. プッシュ通知を使う場合は、MT4の「ツール → オプション → 通知機能」でMetaQuotes IDを設定します。

## 売買ロジック

| | 戦略A：トレンドフォロー | 戦略B：平均回帰 |
|---|---|---|
| 相場条件 | H1のADXが22以上 | H1のADXが20未満、かつH4のADXが25未満 |
| 方向 | H4のEMA50とEMA200の向き | ボリンジャーバンドの外側から内側へ |
| エントリー | H1終値が直近20本の高値・安値を抜ける | H1終値がバンド外、かつRSIが30未満／70超 |
| 損切り | ATRの2.5倍 | ATRの1.5倍 |
| 利確 | なし（ATRの3倍でトレーリング） | ボリンジャーバンドの中央線 |
| 時間決済 | なし | 24本（24時間） |

判断はすべて確定足で行い、H1の新しい足が始まった時だけ評価します。

## リスク管理（既定値）

| 項目 | 既定値 | 動作 |
|---|---|---|
| 1トレードのリスク | 残高の0.5% | 損切り幅からロットを自動計算。最小ロットでも超える場合は見送り |
| 合計リスク上限 | 2.0% | 全銘柄の保有リスク合計がこれを超える新規は見送り |
| USD方向の上限 | 1.5% | USD買い、USD売りそれぞれの合計リスクに上限 |
| 同時保有数 | 6 | 全銘柄合計 |
| 日次損失 | 2.0% | 到達した日は新規エントリー停止（保有分は損切りに任せる） |
| 最大ドローダウン | 15% | 全決済して停止。`ResetHalt=true` を一度入れるまで再開しない |

日次損失とドローダウンは口座の有効証拠金で測るため、手動取引や入出金も影響します。
出金した後は `ResetHalt=true` で一度ピークをリセットしてください。

## 見送りフィルター

- スプレッドがATRの15%を超える
- ATR(14)がATR(100)の2倍を超える（急変時）
- サーバー時間23時〜1時（ロールオーバー）
- 金曜19時以降は新規停止、21時に全決済
- `NewsTimes` に入れた時刻の前後30分

指標カレンダーの自動取得は実装していません。重要指標は `NewsTimes` にサーバー時間で手入力します
（例：`2026.12.04 15:30;2026.12.09 21:00`）。

## 資金の目安

100万円（約6,500ドル）以上を推奨します。
それ未満だと、XAUUSDは最小ロット0.01でも1トレード0.5%を超えやすく、見送りが増えます。

## 検証手順

MT4のストラテジーテスターは1銘柄ずつしか回せないため、銘柄ごとに行います。
合計リスク上限やUSD方向の上限は、バックテストでは検証されません。

1. H1・「全ティック」・変動に近いスプレッドで、銘柄ごとに10年以上を回す。
2. 期間を前半7割（最適化用）と後半3割（検証用）に分け、後半は最後まで触らない。
3. 最適化するのは `Trend_BreakoutBars`、`Trend_SL_ATR`、`Trend_Trail_ATR`、`MR_SL_ATR`、ADX閾値程度に絞る。
4. 選んだ値を±20%ずらしても黒字が保たれるか確認する。

| 合格基準 | 値 |
|---|---|
| プロフィットファクター（検証期間） | 1.3以上 |
| 最大ドローダウン | 15%以下 |
| 取引回数（全期間・4銘柄合計） | 500回以上 |
| 検証期間の成績 | 最適化期間の50%以上 |

5. 合格したらデモ口座で3か月以上動かし、バックテストとの差を確認する。
6. 実運用は最小リスク（例：`RiskPercent=0.25`）から始める。

基準を満たさない戦略・銘柄は、`EnableTrend` / `EnableMeanRev` を切るか、その銘柄から外してください。

## ログ

`MQL4/Files/RobustDuo_<銘柄>.csv` に、エントリー、決済、見送り理由、停止を記録します。
