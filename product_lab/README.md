# 👶 育児プロダクト開発ラボ（Product Lab）

> 「育児に悩む家族にぶっ刺さる商品」を作るためのプロジェクト専用スペースです。
> まずは**負けパターン（失敗事例）を徹底的に学ぶ**ことから始めます。勝ち筋は、他人がどこでコケたかを知ることから見えてきます。

---

## 🎯 このプロジェクトのゴール

育児中の家族が抱える「本当に切実な悩み」に対して、
- 買って後悔されない
- 使い続けてもらえる（チャーンしない）
- 安全で信頼できる
- 価格と価値が釣り合っている

そんな育児プロダクト（モノ／サービス／アプリ）を企画・開発する。

## 🧭 進め方（ロードマップ）

| STEP | 内容 | 成果物 | 状態 |
|---|---|---|---|
| **1. 失敗から学ぶ** | 過去10年の世界の育児プロダクト失敗事例を調査し、課題と改善案を抽出 | `research/failed_products_research.md` | ✅ 着手済み |
| 2. 機会領域の特定 | 失敗パターンの裏返し＋未解決の親の悩みから「狙う場所」を決める | （次回） | ⬜ |
| 3. アイデア発散 | コンセプトを複数出す（`ideas/` に蓄積） | `ideas/*.md` | ⬜ |
| 4. 検証・選別 | 親へのインタビュー/プロトタイプ/簡易テストで筋の良いものを絞る | （次回） | ⬜ |
| 5. 企画書化 | 1本に絞ってビジネス/プロダクト企画書へ | （次回） | ⬜ |

## 🔗 関連

このリポジトリ本体（`/`）は別プロジェクト「小児科コンテンツ自動生成システム」です。
本ラボ（`product_lab/`）はそれとは独立した**商品開発の検討スペース**として切り出しています。
コンテンツ生成システムが持つ「親の悩みデータ・小児科監修の知見」は、本ラボの商品企画にも活かせます。
