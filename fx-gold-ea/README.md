# GoldTrendRider — XAUUSD トレンドフォローEA

ゴールド(XAUUSD)の強いトレンド性を活かすブレイクアウト型EAです。

## 戦略ロジック

| 要素 | 実装 |
|------|------|
| トレンド判定 | EMA(50) と EMA(200) の位置関係 |
| エントリー | ドンチャンチャネル(20本)のブレイクアウト(確定足ベース) |
| レンジ除外 | ADX(14) ≥ 20 のときのみエントリー(任意) |
| 初期ストップ | エントリー価格 ∓ ATR(14) × 2.0 |
| 利伸ばし | シャンデリア・トレーリング(直近22本高安 ∓ ATR × 3.0)。固定TPなし |
| 増し玉 | トレンド継続で ATR × 1.0 順行するごとに追加(最大3ポジション) |
| ドテン | 逆方向のブレイク発生で既存ポジションを決済 |
| ロット | 口座残高に対する%リスクから自動計算(ブローカーのtick value対応) |

### 防御機構(攻め設定でも資金を守る仕組み)

- **スプレッドフィルター**: 指定ポイント超のスプレッド時はエントリーしない
- **日次損失上限**: その日の開始残高から指定%失うと全決済し、翌日まで停止
- **最大ドローダウン停止**: 資金ピークから指定%下落で全決済し、完全停止(再アタッチまで取引しない)
- **証拠金チェック**: フリーマージン不足時はロットを縮小 or 見送り
- **エントリーは確定足のみ**: ティックノイズによるダマシを軽減

## セットアップ

1. `GoldTrendRider.mq4` を MT4 の `MQL4/Experts/` にコピー
2. MetaEditor でコンパイル(F7)— エラー0を確認
3. XAUUSD の **H4チャート** にアタッチ(実データ検証での推奨時間足)
4. `presets/` の .set ファイルをパラメータ画面で読み込み
   - `GoldTrendRider_v12_h4_long.set` … **標準推奨(v1.2)**。買い専用+ATR拡大フィルター(実データH4: +93%/PF3.22/DD16.7%/シャープ1.40)
   - `GoldTrendRider_v12_h4_long_attack.set` … **攻め版**。同ロジックでリスク2.0%(H4: +140%/PF3.27/DD22.3%)
   - `GoldTrendRider_balanced_long.set` … v1.1推奨だった構成(H4: +73%/PF2.13/DD23%)
   - `GoldTrendRider_balanced.set` … 売買両方向のバランス型
   - `GoldTrendRider_aggressive.set` … 攻め設定(リスク3%×3段)。**実データ検証ではDDブレーカー発動で非推奨**
   - `GoldTrendRider_conservative.set` … 検証・フォワードテスト用の堅実設定
5. 自動売買を有効化(ツールバーの「自動売買」ボタン)

> **時間帯フィルターの注意**: `SessionStartHour/EndHour` は**ブローカーのサーバー時間**です。多くの海外ブローカーはGMT+2/+3(NY17時クローズ)なので、デフォルトの7〜21時はおおよそロンドン〜NY時間をカバーします。自分のブローカーのサーバー時間に合わせて調整してください。

## Pythonバックテスター (`backtest/`)

EAと同一ロジックのバックテスターを同梱しています。MT4がない環境でも検証・パラメータ分析が可能です。

```bash
cd backtest && pip install pandas numpy matplotlib
python3 gold_backtest.py --csv XAUUSD60.csv --preset balanced   # MT4エクスポートCSVで実データ検証
python3 run_validation.py                                        # エンジン検証スイート
```

検証結果と主要な発見(**攻め設定はDDブレーカー頻発、リスク1〜1.5%の方が複利効率が高い**)は [backtest/REPORT.md](backtest/REPORT.md) を参照。この結果を受けて `presets/GoldTrendRider_balanced.set` を追加済み。

## MT4でのバックテスト手順(必ず実施してください)

1. ツール → History Center で XAUUSD の H1 と M1 データをダウンロード
2. Strategy Tester (Ctrl+R) で:
   - Expert: GoldTrendRider / Symbol: XAUUSD / Period: H1
   - Model: **Every tick**(最も高精度)
   - Spread: 実際の口座のスプレッドに近い値を指定(可変にしない)
3. 最低でも直近3〜5年でテストし、以下を確認:
   - プロフィットファクター > 1.3
   - 最大DDが自分の許容範囲内か
   - 取引回数が十分か(100回未満なら統計的に信頼できない)
4. 最適化する場合は **In-Sample/Out-of-Sample を分ける**(例: 2021–2024で最適化 → 2025–2026で検証)。全期間で最適化するとカーブフィッティングになります。

## パラメータ一覧

主要なもののみ。全パラメータはソースコードのinput定義とコメントを参照。

| パラメータ | デフォルト | 説明 |
|-----------|----------|------|
| `RiskPercent` | 3.0 | 1エントリーあたりのリスク(残高%)。ピラミッド3段なら合計最大約9% |
| `MaxPyramids` | 3 | 同方向の最大ポジション数 |
| `SlAtrMult` | 2.0 | 初期ストップ幅(ATR倍率) |
| `TrailAtrMult` | 3.0 | トレール幅(ATR倍率)。小さいほど早く利確、大きいほど利を伸ばす |
| `DonchianPeriod` | 20 | ブレイク判定の参照本数。大きいほどエントリー厳選 |
| `MaxDailyLossPct` | 8.0 | 日次損失上限(%) |
| `MaxDrawdownPct` | 35.0 | 完全停止となる最大DD(%) |

# GoldSessionBreakout — 短期セッションブレイクアウトEA

アジア〜ロンドン時間(サーバー1〜15時)のレンジを、ボラティリティが爆発するNY時間(15〜20時)にブレイクした方向へ取るデイトレEA。H4トレンドと同方向のブレイクのみエントリーし、23時に全決済(オーバーナイトなし)。

## セットアップ

1. `GoldSessionBreakout.mq4` を `MQL4/Experts/` にコピーしてコンパイル
2. XAUUSD の **M5 または M15 チャート**にアタッチ
3. プリセット読み込み: `GoldSessionBreakout_standard.set`(リスク1.5%)または `_attack.set`(2.5%)
4. **時刻設定はサーバー時間GMT+2/+3前提**。異なるブローカーでは `RangeStartHour/RangeEndHour/TradeEndHour/EodExitHour` を時差分ずらすこと

## 主要パラメータ

| パラメータ | デフォルト | 説明 |
|-----------|----------|------|
| `RangeStartHour`/`RangeEndHour` | 1 / 15 | レンジ計測ウィンドウ(サーバー時間) |
| `TradeEndHour` | 20 | 未約定ストップ注文の取消時刻 |
| `EodExitHour` | 23 | 全ポジション強制手仕舞い |
| `BufferFrac` | 0.10 | ブレイク判定バッファ(レンジ幅比) |
| `TpRMultiple` | 3.0 | 利確幅=リスクのR倍(0で時間手仕舞いのみ) |
| `UseH4TrendFilter` | true | H4 EMA50/200と同方向のみ(IS検証でPF 1.10→1.30) |
| `RiskPercent` | 1.5 | 1トレードのリスク(残高%) |

GoldTrendRiderとの併走: マジックナンバーが異なる(20260703/20260704)ため同一口座で同時稼働できます。戦略の相関が低く、ポートフォリオとしてDDの平準化が期待できます。

## ⚠️ 免責・リスクについて

- 攻め設定(リスク3%×3段)は**口座資金の大部分を失う可能性が現実にあります**。必ずデモ→少額の順で検証してください。
- 過去のバックテスト成績は将来の利益を保証しません。ゴールドは雇用統計・FOMC・地政学イベントで数分に数十ドル動くことがあり、ストップは滑ります。
- 重要指標の前後は手動でEAを止めることを推奨します(ニュースフィルターは今後のバージョンで実装予定)。
