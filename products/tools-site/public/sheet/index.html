PSA鑑定 収支管理シート

トレカをPSA鑑定に出して売る個人向けの、Excel / Googleスプレッドシート用の収支管理シートです。 1枚ごとの仕入値・鑑定費用・売却額を台帳に入れると、原価と利益、注文別・月別の集計が自動で出ます。

販売準備中

まだ販売を始めていません。販売を始めたら、ここに販売ページへのリンクを掲載します。

何ができるか

  • 在庫台帳: カード1枚を1行で記録します。状態（在庫・鑑定中・返却済・売却済）とグレードはプルダウンで選びます。500行ぶん用意しています。
  • 鑑定費用の自動計算: 為替・鑑定料・往復送料・関税・税率・諸経費を設定すると、1枚あたりの鑑定費用を計算し、原価合計・販売手数料・利益・利益率まで出します。
  • 注文別集計: PSA注文番号ごとに、枚数・仕入合計・鑑定費用合計・売却合計・利益・未売却ぶんの原価を集計します（30注文まで）。
  • 月次集計とグレード別割合: 指定した年の売却月ごとの売上・原価・利益・枚数と、グレード別の枚数・割合（自分のPSA10率）を出します。
  • 仕入れ前シミュレーター: 仕入れ値と、PSA10 / PSA9 / それ以下の売値・確率を入れると、期待利益・損益分岐の仕入れ値・目標利益率からの仕入れ上限を表示します。

黄色いセルが入力欄、灰色のセルは数式です。相場の取得やPSAの注文状況の取得などの自動連携はなく、すべて手入力です。

無料ツールとの違い

1枚あたりの鑑定費用の式は、当サイトの PSA鑑定 損益シミュレーター と同じです。違うのは利益率の定義で、シートは全体を通して「利益 ÷ 売却額」で計算します。 当サイトの PSA鑑定 仕入れ上限 逆算 は目標利益率を「仕入れ値に対して」で計算するため、同じ数字を入れても仕入れ上限は一致しません （一例として、期待売値36,500円・費用15,002円・目標20%のとき、ツールは17,900円、シートは14,100円）。

よくある質問（抜粋）

同梱の「よくある質問」からの抜粋です。

Excel で開いたら、数字が出ず空欄に見えます。

画面上部に「保護ビュー」の黄色い帯が出ていたら、「編集を有効にする」を押してください。このファイルには計算済みの値を入れておらず、開いたアプリがその場で計算する作りです。そのため、販売サイトやスマートフォンのプレビュー表示では、数式のセルが空に見えることがあります。

Googleスプレッドシートで使うには、どうすればいいですか。

Googleスプレッドシートで空のファイルを開き、「ファイル」→「インポート」→「アップロード」で xlsx を選び、「新しいスプレッドシートを作成する」で取り込みます。元の xlsx（購入時の zip）は消さずに取っておいてください。

スマートフォンや、ほかの表計算アプリでも使えますか。

パソコンの Microsoft Excel と Googleスプレッドシートを対象にしています。スマートフォンのアプリでの操作は想定していません（表が横に長く、入力しづらいためです）。Numbers など他の表計算アプリは対象外で、動くかどうかは確認していません。

為替や鑑定料を変えると、過去の行の金額も変わりますか。

変わります。設定は1組だけで、在庫台帳のすべての行が同じ設定を見て鑑定費用を計算するためです。過去ぶんを固定したいときは、その行の「鑑定費用」のセルに実際にかかった金額を直接入力します。注文ごと・サービスレベルごとに料金を持ち分ける機能はありません。

PSA 以外の鑑定会社でも使えますか。

費用の項目名をご自身で読み替えれば、費用と利益の計算には使えます。ただし、グレードの選択肢は「未鑑定 / PSA10 / PSA9 / PSA8以下」の4つで固定で、通貨は円とドルの1組だけです。他社の料金体系や手続きに合うかどうかは確認していません。

シミュレーターの結果どおりに利益が出ますか。相場は自動で入りますか。

いいえ。シミュレーターは、ご自身が入れた売値と確率から平均（期待値）を計算するだけで、将来の相場や鑑定結果を予測するものではありません。利益が出ることを保証するものでもありません。相場や PSA の注文状況を自動で取得する機能はなく、すべて手入力です。

税金や関税の計算は、これで合っていますか。確定申告に使えますか。

このシートは収支の記録と試算のための道具で、税額を計算するものではありません。設定の税率・関税の初期値は一例で、実際の税額や制度を示すものではありません。税務と、関税・輸入時の税の扱いは、必ずご自身で税理士・税務署・税関などに確認してください。

使い方の質問や、不具合の問い合わせはできますか。

個別のサポート（使い方の質問への回答、カスタマイズ、不具合の個別対応）は行っていません。同梱の「よくある質問」とファイル内の「使い方」シートで解決できる範囲でお使いください。バージョンアップ版の提供もお約束していません。

まずは無料ツールで計算する

  • PSA鑑定 損益シミュレータートレカをPSA鑑定に出したときの1枚あたりの費用・期待利益・利益率・損益分岐の仕入れ値を計算します。PSA10・PSA9になった場合の損益も表示。
  • PSA鑑定 仕入れ上限 逆算PSA鑑定の費用と目標利益率から「この値段までなら仕入れてよい」上限額を逆算します。
  • 鑑定料の円換算ドル建ての鑑定料を、枚数・為替・送料から1枚あたりと合計の円額に換算します。
  • トレカ売買の利益率計算仕入れ値・売値・販売手数料率・送料から、利益・利益率・損益分岐の売値を計算します。フリマやオークションでの転売に。
  • フリマと買取の手取り比較同じカードをフリマで売った場合と買取に出した場合の手取りを比べ、差額と、手取りが同じになる買取率を計算します。

計算の考え方の解説

  • 鑑定に出すときの1枚あたり費用の数え方鑑定料・往復送料・輸入時にかかる費用・諸経費を、1枚あたりに直して足す考え方を、計算例つきで説明します。
  • 損益分岐の仕入れ値と、グレードが下振れしたときの損益の見方期待売値から費用を引いて損益分岐の仕入れ値を出す考え方と、PSA9以下だった場合の損益の見方、期待値で考える意味と限界を説明します。
  • 鑑定転売の記録の付け方（1枚ごとに何を残すか）カード1枚を1行で記録するときに、どの項目を残しておくと注文別・月別・グレード別に後で集計できるかを説明します。
