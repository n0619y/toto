# kaitori-site（未鑑定カードの郵送買取 受付サイト）

ポケモンカードの未鑑定カード（素体）の郵送買取を受け付けるための、静的なサイトです。
目的は「問い合わせを減らすこと」。価格の決め方・対象・状態基準・流れ・よくある質問を、申込の前にすべて読めるようにしています。
運用の中身（ルールの原稿、定型文、フォームの作り方、確認事項）は `products/kaitori-kit/` にあります。

作りは `products/tools-site/` と同じです。`build.py`（Python 標準ライブラリだけ）が `public/` に静的HTMLを生成します。

```
python build.py            # public/ を生成
python build.py --check    # 公開前に直す項目の一覧（生成はしない）
node --test src/test.mjs   # 手取り計算のテスト（kaitori-kit/tejori.py と突き合わせる）
```

## ページ

| パス | 内容 |
|---|---|
| `/` | 何を・いくらで・どういう流れで買うか。価格の式、対象と対象外、最低ロット、振込までの日数、申込ボタン（または「受付準備中」） |
| `/simulator/` | 手取りシミュレーター。フリマで売った場合とこの買取の手取り・差額・手取りが同じになる買取率。フリマのほうが多い条件ではそのとおり表示する |
| `/rules/` | 買取ルール（`kaitori-kit/買取ルール.md` が元） |
| `/condition/` | 状態基準（A/B/C）と写真の撮り方 |
| `/flow/` | 買取の流れ（申込 → 仮査定 → 発送 → 検品 → 承諾 → 振込）と各段階の期限 |
| `/faq/` | よくある質問（14問） |
| `/about/` | 運営者情報・個人情報の扱い |
| `/404.html` | 存在しないURL用（noindex。sitemap に入れない） |

全ページに、固有の title と description（空・重複があるとビルドが止まる）、canonical、ライト/ダークの配色が入ります。
`sitemap.xml` と `robots.txt` も生成します。

## 申込ボタンが出る条件

`site.json` の次の4つがすべて入るまで、申込ボタンは出ず「受付準備中」と表示されます。

- `kobutsu_iinkai`（古物商許可を受けた公安委員会の名前）
- `kobutsu_bango`（古物商許可の番号）
- `honnin_kakunin`（本人確認の方法）
- `form_url`（申込フォームのURL。`https://` から）

受付を一時的に止めるときは `uketsuke_teishi` を `true` にしてビルドし直します
（ボタンの代わりに「現在、新規の受付を停止しています」と出ます）。フォーム側の受付も止めてください。

## 公開までの手順

1. **確認を済ませる。** `kaitori-kit/確認事項.md` の 1〜8 を、それぞれの確認先に問い合わせる。
   法律・税務に関わる文（本人確認の方法、未成年の扱い）は、このサイトでは決めていません。確認した結果を `site.json` に書きます。
2. **値を決めて `site.json` に書く。** 下の表のとおり。空の項目は、ページのその箇所に「準備中」と出ます。
3. **フォームを作る。** `kaitori-kit/申込フォーム項目.md` の手順で作り、公開リンクを `form_url` に入れる。
4. `python build.py --check` で「公開前に直す項目」が 0 件になるまで直し、`python build.py` で生成する。
5. `public/` を静的サイトのホスティングに置く（ドメイン直下。`404.html` を自動で返すサービスを想定）。
6. 公開後に値を変えたら、`koshinbi`（最終更新日）も直してビルドし直す。

### site.json の項目

| キー | 書くもの | どこに確認して決めるか |
|---|---|---|
| `name` | 屋号 | 許可・届出の名義との書き分けは、所轄の警察署（古物の担当窓口） |
| `url` | 公開URL（`https://` から。末尾の `/` は不要） | 公開先のサービスで決まる |
| `kobutsu_iinkai` / `kobutsu_bango` | 古物商許可の公安委員会の名前と番号 | 許可証のとおり |
| `shozaichi` | 所在地（都道府県と市まで。番地は書かない） | 表示が求められる範囲は所轄の警察署 |
| `eigyobi` | 営業日 | 自分で決める |
| `contact` | 連絡先（問い合わせ用のメールアドレスなど。個人の電話番号は書かない） | 自分で決める |
| `form_url` | 申込フォームのURL | `kaitori-kit/申込フォーム項目.md` |
| `honnin_kakunin` | 本人確認の方法（売り手に見せる文） | 所轄の警察署に、郵送買取で認められる方法を確認 |
| `miseinen` | 未成年の方の扱い（売り手に見せる文） | 所轄の警察署、都道府県の条例の担当窓口 |
| `kaitoriritsu` | 買取率（%。数字だけ。状態 A） | 自社の数字（`確認事項.md` の 7） |
| `jotai_b` | 状態 B の買取額（文） | 自社の数字 |
| `soba_name` | 基準にする相場の名前（1つに固定） | 出典側の利用規約（名前と数字を載せてよいか） |
| `soba_hoho` / `soba_taishogai` | 基準相場の出し方 / 出せない条件 | 自分で決める |
| `taisho_list_url` | 対象カードのリストのURL | 自分で作る |
| `soba_kagen` | 対象とする1枚あたり相場の下限（円。数字だけ） | 鑑定の1枚あたり費用から |
| `min_lot` | 最低ロット（文） | 自分で決める |
| `soryo` / `henkyaku_soryo` | 当店への発送の送料の扱い / 返却の送料の扱い（文） | 自分で決める。配送方法は配送会社の補償の条件を確認 |
| `furikomi_days` | 承諾から振込までの営業日数（数字だけ） | 自分で決める |
| `furikomi_tesuryo` / `saifurikomi_tesuryo` | 振込手数料の扱い / 再振込のときの扱い（文） | 自分で決める |
| `kigen_karisatei` / `kigen_hasso` / `kigen_kenpin` / `kigen_henshin` / `kigen_henkyaku` | 各段階の期限（数字だけ。仮査定・検品・返却発送は営業日、発送・返信は日） | 自分で決める |
| `jotai.*`（10個） | 状態基準の数値と判定のしかた | 自分で決める（例は `kaitori-kit/買取ルール.md` の 4.） |
| `koshinbi` | 買取ルールの最終更新日 | ルールを変えた日 |
| `uketsuke_teishi` | `true` で受付停止の表示 | 受けられる件数を超えたとき |

それぞれの書き方の例は `python build.py --check` の一覧に出ます。
送料や振込手数料を売り手の負担にする場合、買取率によってはフリマのほうが手取りが多くなります
（`kaitori-kit/計算例.md` の例3）。シミュレーターはその場合もそのとおり表示します。

## 書かないと決めていること

- 法律・税務についての断定的な説明。本人確認は「古物営業法にもとづき行う。方法は申込後に案内」とだけ書き、方法は `honnin_kakunin` の値を表示する。
- 誇張した言い回し、他店の名指し、鑑定の結果の保証、取引と結びついた景品の告知。
- 鑑定会社・フリマ・相場サイトの具体名（相場の名前は `soba_name` の値だけを表示）。
- 実在の個人名・住所・電話番号。
- `site.json` の値に上のような言い回しが入ると、`--check` が知らせます（`build.py` の `NG_WORDS`）。

## ファイル

| ファイル | 中身 |
|---|---|
| `site.json` | 運営者が埋める値 |
| `build.py` | 全ページの本文とテンプレート、`--check` |
| `src/style.css` | `tools-site` の CSS に、このサイト用の指定を数行足したもの |
| `src/tejori.js` | 手取りの計算（`kaitori-kit/tejori.py` の売り手の視点と同じ式・同じ端数処理） |
| `src/app.js` | シミュレーターの画面 |
| `src/test.mjs` | 計算のテスト。計算例の数字と、`tejori.py` との突き合わせ（乱数500件） |

シミュレーターの販売手数料率 10%・送料 210円の初期値は `kaitori-kit` の例と同じ「一例」です。買取率の初期値は `site.json` の `kaitoriritsu` です。
