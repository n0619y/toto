買取の流れ

申込から振込まで、だれが・いつまでに・何をするかをまとめました。営業日: 準備中

  1. 申込
  2. 仮査定
  3. 発送
  4. 検品
  5. 承諾
  6. 振込
  1. 1. 申込（お客様）申込フォームから、カードの一覧（カード名・型番・枚数・ご自身で見た状態）と、写真の共有リンクを送ります。写真の撮り方は状態基準をご覧ください。番地までの住所や口座情報は、この段階ではお聞きしません。
    期限: なし
  2. 2. 仮査定の連絡（当店）対象リストと照らし合わせ、写真から見た状態で仮査定（参考価格）をお知らせします。対象外の場合はその旨をお知らせします。
    期限: お申し込みから準備中
  3. 3. 発送（お客様）仮査定をご確認のうえ、カードを発送します。送料の扱い: 最低ロットを満たすお申込みは当店負担（指定の方法の着払い）。本人確認はお取引の前に行います（方法は仮査定のご連絡とあわせてご案内します）。
    期限: 仮査定のご連絡から準備中。過ぎた場合、お申し込みは取り消しとなります
  4. 4. 検品（当店）届いた日の基準相場で買取額を計算し直し、1枚ごとに状態区分・確定額・理由（該当箇所の写真つき）をお知らせします。到着したことは、届いた翌営業日までにお知らせします。
    期限: 到着から準備中
  5. 5. 承諾または返却（お客様）1枚単位で「承諾」か「返却」を選んでご返信ください。承諾の後は買取が成立し、取り消しはできません。お振込先はこのときにお聞きします（ご本人名義の口座）。
    期限: 検品結果のご連絡から準備中。期限の前日に一度ご連絡します。ご返信が無い場合は全点を返却します
  6. 6. 振込（当店）承諾いただいたカードの確定額を振り込み、振込のご連絡をします。振込手数料: 当店が負担します
    期限: 承諾のご連絡から3営業日以内

返却がある場合

返却を選ばれたカードは、返却の確定から準備中に発送します。返却の送料の扱い: 準備中

ご連絡について

ご連絡は、段階ごとに決まった文面でお送りします。期限に間に合わない見込みのときは、期限の前にその旨をお知らせします。

受付準備中

古物商許可の表示と本人確認の方法の準備ができしだい、受付を始めます。それまでは、買取ルールと手取りシミュレーターをご覧いただけます。
