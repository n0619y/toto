## 1. 古物商許可の名義・営業所と、郵送買取での本人確認

確認すること:

- 許可の名義(個人か法人か)と、屋号「toto mint」で買取を行うことの関係。
  許可証の氏名・名称と、サイトや X に表示する名義をどう書けばよいか。
- 届け出ている営業所の所在地と、カードを受け取る場所・保管する場所が同じでよいか。
  違う場合に手続きが要るか。
- ウェブサイトや X で買取の申込を受ける場合に、届出が要るか(URL の届出など)。
  X のアカウントやフォームの URL はその対象になるか。
- サイト等に表示が求められる事項(許可を受けた公安委員会の名称、許可番号、氏名または名称など)と、表示する場所。
- **郵送買取(相手と対面しない取引)で認められる本人確認の方法。**
  身分証のコピーを受け取るだけでは足りないとされています。
  法令に定められた方法のうち、どれを採るかを決めるために、次を聞きます。
  - 現在認められている方法の一覧と、それぞれの手順
    (例として挙がることがあるもの: 本人限定受取郵便を使う方法、
    身分証の写しを受け取ったうえで、その住所あてに転送不要の書留等を送り到達を確かめる方法、
    身分証の写しを受け取ったうえで本人名義の口座に振り込む方法、オンラインで本人確認を行う方法 など。
    これらが現在も認められているか、条件は何かを確認する)
  - 当店の流れ(申込 → 仮査定 → 発送 → 検品 → 承諾 → 振込)の、どの時点までに確認を終える必要があるか
  - 2回目以降の取引での扱い
  - 本人確認の記録として残すものと、保存の期間
- 買い取った品に盗品の疑いがあるときの手順(申告の方法、品物の扱い)。
- 相手方の確認が要らないとされる取引の範囲があるか(2. とあわせて)。

## 4. フリマサービスの規約

フリマサービスの出品者に対して、サービスの外での直接取引を持ちかけることは、
多くのサービスで禁止されています。そのため、**フリマ内での勧誘はしません。**

確認すること(自分が使っている各サービスの規約・ガイドで):

- コメントやメッセージで外部の取引に誘うこと、外部の連絡先や URL を載せることの扱い。
- プロフィールや商品説明に、外部の買取サービスの案内を書くことの扱い。
- 違反した場合の措置(利用制限など)。仕入れと販売に使っているアカウントへの影響。

自社方針の案:

- フリマの中(コメント、メッセージ、プロフィール、商品説明)では買取に触れない。
- 集客は X と自社ページだけで行う。
- 告知では「フリマで売った場合の手取りとの計算上の比較」だけを書き、
  特定のサービスの名前を出して優劣を述べない。サービス名を出す必要があるかどうかも検討する
  (手数料率を引用する場合は、出典と確認日を書く)。

## 5. 景品企画と景品表示法、X のキャンペーンルール

確認すること:

- フォローとリポストだけを条件にする抽選が、景品表示法の上でどの類型にあたるか。
  取引を条件にしない場合の扱いと、取引を条件にした場合の景品の上限額の違い。
- 買取(当店が買う側)の取引に付ける景品が、どう扱われるか。
  → 判断が分かれうるので、当店は取引と景品を結びつけない方針とする。
- 「フリマより手取りが多い」という表示が、有利であると誤認させる表示にあたらないための条件
  (前提の数字、適用されない場合の明記、根拠の保存)。
- X のキャンペーンに関する規約(複数アカウントでの応募を促さない、同じ内容の投稿を繰り返させない など)。
- 当選者から受け取る個人情報(送付先)の扱い。
- 景品の内容が、他社の権利や転売の決まりに触れないか。

自社方針の案: 条件はフォローとリポストだけ。買取の申込・成立を、応募や当選の条件にも、
当選確率を上げる条件にもしない。その旨を募集のポストに書く。

## 6. 他社の名称(PSA など)やロゴの使い方

確認すること:

- 鑑定会社の名称を文中で使うことについて、各社が公開している決まりがあるか。
- ポケモンカードの名称・カード画像を、告知や対象リストで使うことについての決まり
  (権利者が公開しているガイドライン)。
- 相場の出典として他社のサイト名を載せること、その数字を引用することについての、出典側の利用規約。

自社方針の案:

- 鑑定会社のロゴ、ラベルの意匠、それに似せた画像は使わない。
- 名称は、事実を説明するための文中の表記にとどめる(例: 「◯◯社に鑑定を依頼しています」)。
- 「公認」「提携」「正規」など、関係があると読める書き方をしない。
  買取ルールに「鑑定会社の公認店・提携店ではありません」と書く。
- 鑑定の結果を予測・保証しない。当店の状態区分を鑑定の評価と結びつけて説明しない。
- カードの写真は、自分で撮った実物の写真だけを使う。
