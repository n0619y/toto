# X 運用

目的は2つです。買取の条件を誰でも確かめられる形で出しておくこと、取引が期限どおりに進んでいる事実を積み上げること。
投稿は型に沿って予約し、その場で考えて書く投稿を無くします。数字とカード名は【 】を埋めて使います。

## プロフィール文の案

X の自己紹介は160字までです。場所の欄に【◯◯県◯◯市】、リンクの欄に買取ルールの URL を入れます。

**案1(計算式を前に出す)**

```
【屋号】|ポケモンカード未鑑定品の郵送買取。買取額=公開相場×【93】%。ご自身で計算できます。対象カードと最低ロットは固定ポストへ。古物商許可【◯◯県公安委員会 第◯◯◯◯号】。お取引のご連絡はメールのみ。
```

**案2(フリマとの比較を前に出す)**

```
【屋号】|ポケカ未鑑定品を郵送で買い取ります。フリマの販売手数料と送料を引いた手取りと比べてみてください。計算例と買取ルールは固定ポストに。対象カードのみ・【合計5万円または10枚】から。古物商許可【◯◯県公安委員会 第◯◯◯◯号】
```

**案3(流れと期限を前に出す)**

```
【屋号】|ポケカ未鑑定品の郵送買取。申込→仮査定(【2】営業日以内)→発送→検品→承諾→振込(【2】営業日以内)。減額は1枚ごとに理由つき、返却も1枚単位で選べます。古物商許可【◯◯県公安委員会 第◯◯◯◯号】
```

## 固定ポストの案

**案1(条件の一覧)**

```
【屋号】 の郵送買取

・買取額 = 公開相場 × 【93】%(状態A)
・対象カードのみ(リストはリンク先)
・【合計5万円以上 または 10枚以上】から
・仮査定は参考価格。到着日の相場で確定
・減額は1枚ごとに理由つき。返却は1枚単位で選べます
・振込は承諾から【2】営業日以内

ルールと申込:【URL】
```

**案2(計算例)**

```
フリマで売る場合と比べてみてください(数字は例)

相場 10,000円のカード
・フリマ: 手数料10%と送料210円を引いて 手取り 8,790円
・【屋号】: 10,000円 × 【93】% = 9,300円(送料・振込手数料は当店負担)

手数料率と送料はサービスや発送方法で変わります。
対象カード・状態基準・申込はこちら:【URL】
```

運営者向けメモ: 案2の「送料・振込手数料は当店負担」は、そう決めた場合だけ書きます。
売り手負担にした場合は、その額を引いた手取りを `tejori.py` で出して書き換えます。

## 投稿の型(8種類)

### 型1: 対象カードと買取率の告知

```
【買取対象の更新】【◯月◯日】時点

・【カード名】(【型番】)
・【カード名】(【型番】)
・【カード名】(【型番】)

買取率は【93】%(状態A)。買取額は到着日の公開相場で計算します。
対象リストの全体と申込は固定ポストから。
```

### 型2: 計算例

```
計算例(【◯月◯日】の相場で計算)

【カード名】(【型番】)
公開相場 【 】円 × 【93】% = 【 】円(状態A)

同じ価格でフリマに出した場合は、手数料【10】%と送料【210】円を引いて 手取り【 】円。
相場は日々動きます。買取額は到着日の相場で確定します。
```

### 型3: 取引完了の報告

金額、カード名と枚数の組み合わせ、地域、アカウント名は出しません。

```
【取引完了】【◯月】【◯】件目

申込から振込まで【 】日(承諾から振込まで【 】営業日)。
ありがとうございました。
```

### 型4: 状態基準の解説

```
状態基準のはなし:【白かけ】

当店では、裏面の四隅と四辺を見ます。
・A: 白かけが見えない
・B: 点状の白かけが【2】か所まで
・C: 【3】か所以上、または線状

暗い色の台に置いて撮ると、申込の前にご自身で確かめやすくなります。
当店の基準であり、鑑定の結果を示すものではありません。
```

(【 】の題材を 傷 / 白かけ / 角 / 反り / センタリング / 写真の撮り方 で回します)

### 型5: よくある質問

```
Q. 仮査定と確定額が違うことはありますか?

A. あります。仮査定は写真と申込日の相場で出す参考価格で、確定額は到着日の相場と実物の検品で決まります。
確定額にご納得いただけない場合は、1枚単位で返却を選べます。
```

題材の候補:

- 対象外のカードを同梱したらどうなるか
- 送料はどちらが負担するか
- 減額されたときはどうなるか
- 本人確認はどう行うか
- 振込はいつか
- 未成年は申し込めるか
- なぜ対象カードを絞っているのか
- DM で申し込めるか

### 型6: 受付状況

```
【受付状況】【◯月◯日】

新規の申込: 【受付中 / 一時停止中】
検品待ち: 【 】件
仮査定のご連絡: 申込から【2】営業日以内

【停止中の場合: 再開は【◯月◯日ごろ】の予定です。再開時にお知らせします。】
```

### 型7: 鑑定結果の共有

当店が鑑定に出したカードの結果を、まとめて共有します。どの取引で仕入れたカードかは書きません。
結果は事実だけを書き、今後の結果を予告したり、当店の状態区分と結びつけたりしません。

```
【鑑定結果】【◯月】に返ってきた分

提出【 】枚の内訳
・10: 【 】枚
・9: 【 】枚
・8以下: 【 】枚

鑑定の結果はカードごとに違います。当店の状態区分は、鑑定の結果を保証するものではありません。
```

### 型8: 実績のまとめ(月1回)

```
【◯月の実績】

・取引完了: 【 】件
・申込から仮査定まで: 平均【 】営業日
・到着から検品結果まで: 平均【 】営業日
・承諾から振込まで: 平均【 】営業日(最長【 】営業日)
・期限を過ぎた連絡: 【 】件

期限を過ぎた場合は、その件数も載せます。
```

### 番外: フォロー&リポストの抽選(取引と結びつけない)

条件はフォローとリポストだけにします。買取の申込や取引の有無を、応募や当選の条件にしません。
実施の前に `確認事項.md` の 5 を確認します。

```
【プレゼント】【景品名】を【 】名に

応募方法: このアカウントをフォロー + このポストをリポスト
締切: 【◯月◯日 23:59】
当選のご連絡: 【◯月◯日】までに DM でお知らせします

買取のお取引の有無は、応募・当選に関係ありません。
```

## やらないこと

- **煽り。** 「今だけ」「急いで」「残りわずか」のように、判断を急がせる書き方をしない。
- **最高値の断定。** 「どこよりも高い」「業界一」のような、確かめられない順位を書かない。
  書くのは計算式と、その日の計算結果だけ。
- **他店の名指し比較。** 他店や個人のアカウント名を出して比べない。比べる相手は
  「フリマで売った場合の手取り」という計算だけ。
- **鑑定結果の保証。** 「当店の状態Aは鑑定で高い評価になる」のような書き方をしない。
  鑑定会社のロゴやラベルの意匠を画像に使わない。公認・提携と読める書き方をしない。
- **取引と結びつけた景品。** 「買取成立で抽選」「申込で進呈」のような企画をしない。
- **フリマ内での勧誘。** フリマサービスの出品者に、コメントやメッセージで直接取引を持ちかけない。
- **個人が特定される情報の投稿。** 取引相手の氏名、アカウント名、地域、金額、
  カードと枚数の組み合わせ、やりとりの画面を出さない。
- **DM での取引。** 個人情報や口座情報を DM で受け取らない。DM にはフォームの案内だけを返す。
- **結果の見込みを語ること。** 相場の先行きや「値上がりしそう」といった予想を書かない。
- **言い返すこと。** 批判的な返信には、買取ルールの該当箇所を一度示すだけにする。
