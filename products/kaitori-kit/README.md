# 素体の郵送買取 運用キット

ポケモンカードの未鑑定カード(以下「素体」)を、売り手から直接、郵送で買い取るための一式です。
やりとりを定型文に、判断をルールに落として、誰が対応しても同じ結果になることを目的にしています。

- このキットの数字はすべて「例」です。運営者が決めた値に置き換えてから公開してください。
- 【 】は運営者が埋める箇所、{ } は定型文の差し込み項目です。
- 法律・税務に関わる部分は「案」です。公開前に `確認事項.md` の確認を済ませてください。

## 仕組み(1枚で)

1. 価格は「公開されている相場 × 買取率」。売り手が自分で計算できる。
2. フリマでは販売手数料と送料が売り手負担。相場の一定割合(例: 93%)で買えば、
   売り手の手取りはフリマより多く、当店はフリマで買うより安く仕入れられる(`計算例.md`)。
3. 買うカードは対象リストに絞る。対象外は断る。最低ロットを設ける。
4. 見積は参考価格。確定は到着日の相場で再計算。これを申込の前に明示する。
5. 状態は自社基準(A/B/C)で判定。減額は1枚ごとに理由を示し、売り手は1枚単位で承諾か返却を選べる。
6. 連絡は定型文、各段階に期限を置く。

### 決めるときの注意

- **買取率は自社の数字から決める。** `確認事項.md` の 7 にある3つの数字
  (現在の仕入れ単価、鑑定後の売値、1枚あたり費用)を出してから決めます。93% は例です。
- **送料と振込手数料を売り手負担にすると、売り文句が成り立たない場合がある。**
  相場1万円・買取率93%で売り手が送料520円を負担すると、手取りは 8,780円で、
  フリマの 8,790円を下回ります(`計算例.md` の例3)。売り手負担にする場合は、
  告知の計算例にその負担を含めてください。
- **最低ロットの「10枚以上」だけだと、合計額が小さい申込が通る。**
  当店が送料と振込手数料を負担する場合、合計1万円の申込では費用が買取額の1割ほどになります。
  「10枚以上かつ合計【 】円以上」とする案もあります。
- **相場の出典は1つに固定する。** 出典が複数あると、どれを使うかで判断が分かれます。
- **受付の上限を置く。** 対応できる件数を超えたら、X とフォームの冒頭で受付停止を知らせます
  (`X運用.md` の型 6)。

## 始める前に確認すること

`確認事項.md` に詳しく書いています。項目だけ挙げます。

1. 古物商許可の名義・営業所と、郵送買取(非対面取引)で認められる本人確認の方法
2. 古物台帳の記載・保存の要件、少額取引の扱い
3. 18歳未満からの買取の扱い(条例と自社方針)
4. フリマサービスの規約(フリマ内での勧誘はしない)
5. 景品企画と景品表示法、X のキャンペーンルール
6. 他社の名称(PSA など)やロゴの使い方
7. 買取率を決めるための自社の数字
8. 税務上の扱い(税理士に確認)

## 運用の決まり(対応する人が変わっても同じ結果にするために)

- 価格は計算式のとおり。個別の値上げ・値下げ交渉には応じない(`定型文.md` の末尾「よくある問い合わせへの返し」を使う)。
- 対象リストに無いカードは買わない。例外を作らない。
- 状態の判定は `買取ルール.md` の表のとおり。迷ったら低いほうの区分にし、理由と写真を添える。
- 検品は到着時の開封から動画または写真で記録する(行き違いが起きたときの確認用)。
- 連絡は定型文を使い、期限を過ぎそうなときは先に遅れを知らせる(定型文 11)。
- 取引ごとに `古物台帳の列.md` の項目を記録してから振り込む。
- 取引と景品を結びつけない。X の抽選はフォローとリポストだけを条件にする。

## 買取率と対象の決め方（試算から分かった考え方）

事業の実数を使った試算は、このリポジトリには入れていません（オーナーの手元にあります）。
ここには、数字に依らない考え方だけを書きます。

- **対象は「1枚あたりの相場」で区切る。** 枚数で足切りしても、安いカードがまとめて届くと成り立たない。
  鑑定の1枚あたり費用が相場に対して大きいカードは、買取率をどう置いても利益が残らないので対象外にする。
  下限の相場は、利用する鑑定プランの費用から決める（費用が下がれば、対象にできる価格帯が広がる）。
- **買取率には下限と上限がある。** 下限は「売り手がフリマで売った場合の手取りと同じになる率」、
  上限は「こちらがフリマで買うより安くなる率」と「目標の粗利率を保てる率」の低いほう。
  この間に収まるカードだけを対象にする。相場の 100%（満額）での買取は、フリマで買うより高くつく。
- **最低ロットは「相場の合計額」で置く。** 送料と振込手数料をこちらが持つ場合、
  その合計が相場の合計に対して何%になるかで決める（例: 合計が大きいほど負担の割合は下がる）。
- **郵送で届くカードは、自分で選んで仕入れたカードより状態のばらつきが大きいと見込む。**
  自分の過去の最高グレード取得率をそのまま当てはめず、最初は低めに置いて、実績がたまったら直す。
- 計算は `tejori.py`（売り手側）で確かめられる。
