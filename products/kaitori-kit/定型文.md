# 定型文

- { } は差し込み項目。送る前に、{ } が残っていないか確かめます。
- 【 】は運営者が最初に一度だけ埋める箇所(期限の日数、URL など)。数字は例です。
- 件名の先頭に受付番号を付けます。文面は変えずに使います。
- 署名は共通です。
- 流れは 申込 → 仮査定 → 本人確認(初回)→ 発送 → 検品 → 承諾 → 振込。本人確認まわりは 2 → 4-A →(4-C)→ 4-B の順に使います。
- 買取額は到着日の相場で確定します。仮査定の金額を据え置く・保証すると読める文は、どの文面にも足しません。

```
【屋号】
古物商許可: 【◯◯県公安委員会 第◯◯◯◯◯◯◯◯◯◯◯◯号】
【◯◯県◯◯市】 / 【メールアドレス】
買取ルール: 【URL】
```

## 差し込み項目の一覧

| 項目 | 内容 |
|---|---|
| {氏名} | 申込者の氏名 |
| {受付番号} | 例: K261201-01 |
| {枚数} | 枚数 |
| {仮査定合計} | 仮査定の合計額 |
| {仮査定明細} | 1枚ごとの明細(カード名 / 基準相場 / 買取率 / 仮査定額) |
| {相場確認日} | 仮査定に使った相場の日付 |
| {郵便発送日} | 本人限定受取郵便を当店が差し出した日 |
| {発送期限} | 発送の期限の日付(発送のお願い 4-B を送った日から数える) |
| {到着日} | 当店に到着した日 |
| {検品期限} | 検品結果を連絡する期限の日付 |
| {検品明細} | 1枚ごとの明細(カード名 / 状態 / 到着日の基準相場 / 確定額 / 理由) |
| {確定合計} | 確定額の合計 |
| {返信期限} | 承諾・返却の返信期限の日付 |
| {振込日} | 振込を行った日 |
| {振込額} | 振り込んだ金額 |
| {追跡番号} | 返却時の追跡番号 |
| {対象外理由} | 対象外・お断りの理由 |
| {不備内容} | 本人確認・口座名義の不備の内容 |
| {カード名} / {型番} | 明細の1行に入れるカード名と型番 |
| {口座下3桁} | 振込先の口座番号の下3桁 |
| {新しい期限} | 当店の連絡が遅れるときの、新しい期限の日付 |

## 1. 自動返信(フォームの確認メッセージ)

```
お申し込みありがとうございます。【屋号】 です。

内容を確認し、【2】営業日以内に、仮査定の結果をメールでお知らせします。
ご入力のメールアドレスに、申込内容の控えをお送りしました。

・仮査定は参考価格です。買取額は、到着日の相場で計算し直して確定します。
・初回のお取引では、仮査定のあとに本人確認を行います。お申し込みのご住所あてに本人限定受取郵便をお送りし、
  ご本人の受け取りを確認できてから、発送をご案内します。
・カードは、当店から発送のご案内が届くまで送らないでください。

控えのメールが届かない場合は、迷惑メールのフォルダをご確認ください。
```

## 2. 仮査定の連絡

件名: 【{受付番号}】仮査定の結果(【屋号】)

```
{氏名} 様

【屋号】 です。お申し込みありがとうございます。
仮査定の結果をお知らせします。

受付番号: {受付番号}
仮査定の合計: {仮査定合計} 円({枚数}枚、{相場確認日} 時点の相場で計算)

{仮査定明細}

・この金額は参考価格です。買取額は、到着日の相場で計算し直して確定します。
・状態は写真から判断しています。実物の検品で区分が変わることがあります。
・確定額にご納得いただけない場合は、1枚単位で返却を選べます。

お進みになる場合は、このメールへのご返信で、次の2点をお知らせください。

1. 「進めます」の一言
2. 生年月日、ご職業(お取引の記録に必要な項目です)

ご返信のあと、お申し込みのご住所あてに本人限定受取郵便をお送りします(初回のお取引の本人確認です)。
ご本人の受け取りを確認できてから、発送の方法をご案内します。カードはまだ送らないでください。

・郵便が届いて受け取られるまで、日数がかかります。
・買取額は、カードが当店に届いた日の相場で確定します。郵便をお待ちいただくあいだに相場が動くことがあり、
  仮査定の金額はそのあいだ据え置かれるものではありません。
・見送られる場合は、ご返信は不要です。
```

運営者向けメモ: 返信が無い申込は先へ進めません(進行中の件数にも数えません)。
2回目以降の取引で郵便を送らない運用に決めた場合(【運営者が決める】)は、「ご返信のあと〜送らないでください。」の段落と
「郵便が届いて〜」の行を「ご返信のあと、発送の方法をご案内します。」に置き換えた文面を別に用意します。

## 3. 対象外のお断り

件名: 【{受付番号}】お申し込みについて(【屋号】)

```
{氏名} 様

【屋号】 です。お申し込みありがとうございます。
申し訳ありませんが、今回のお申し込みは買取をお受けできません。

理由: {対象外理由}

対象カードと最低ロットは、買取ルールのページでご確認いただけます。
対象リストは随時更新しています。条件が合うときに、またお申し込みください。
```

{対象外理由} の選択肢(このどれかを入れる):

- お申し込みのカードが対象リストにありません。
- 対象カードの仮査定の合計が、最低ロット(5万円以上)に届いていません。
- 1枚あたりの基準相場が 30,000円に満たないカードです。
- 写真から、当店の状態基準で C にあたると判断しました。
- 基準相場を出せるだけの成約件数がありません。
- 現在、新規の受付を停止しています。
- 買取ルールの「未成年の方」「禁止事項」により、お受けできません。

一部だけ対象外の場合は、定型文 2 の明細に「対象外(理由)」と書き、この定型文は使いません。

## 4-A. 本人確認の郵便を送りました(初回のお取引)

仮査定(定型文 2)に「進めます」と返信があり、本人限定受取郵便を差し出した日に送ります。

件名: 【{受付番号}】本人確認の郵便をお送りしました(【屋号】)

```
{氏名} 様

【屋号】 です。ご返信ありがとうございます。
古物営業法にもとづく本人確認のため、{郵便発送日} に、お申し込みのご住所あてに本人限定受取郵便をお送りしました。

・郵便局からの通知に従って、ご本人がお受け取りください。
・受け取りを当店で確認できましたら、発送の方法(発送先・期限)をメールでご案内します。
  それまで、カードは送らないでください。
・郵便の費用: 【運営者が決める。例: 当店が負担します】
・買取額は、カードが当店に届いた日の相場で確定します。郵便をお待ちいただくあいだに相場が動くことがあり、
  仮査定の金額はそのあいだ据え置かれるものではありません。

お取引を見送られる場合は、このメールへのご返信でお知らせください。
```

運営者向けメモ: 郵便の受け取りの確認のしかた(何を見て「受け取った」とするか)と、残す記録は、
所轄の警察署に確認した手順に従います(`古物台帳の列.md` の「本人確認」の列に記録)。

## 4-B. 発送のお願い(本人確認の完了後)

郵便の受け取りを確認できた日の翌営業日までに送ります。{発送期限} は、このメールを送った日から数えます。

件名: 【{受付番号}】発送のご案内(【屋号】)

```
{氏名} 様

【屋号】 です。本人限定受取郵便のお受け取りを確認できました。ありがとうございます。
カードの発送をお願いします。

発送先: 【発送先の住所・宛名】

発送の方法:
・【配送会社・サービス名】の着払いでお送りください(送料は当店が負担します)。
・カードは1枚ずつスリーブとローダーに入れ、水ぬれ防止の袋に入れてください。
・箱の中に、受付番号 {受付番号} を書いたメモを入れてください。
・発送後、追跡番号をこのメールへのご返信でお知らせください。

発送の期限: {発送期限}
期限までに発送のご連絡が無い場合、お申し込みは取り消しとなります。

買取額は、カードが当店に届いた日の相場で計算し直して確定します(仮査定は参考価格です)。
```

運営者向けメモ: 発送先は、受け取りを確認する前には知らせません(このメールで初めて知らせます)。
確認の前にカードが届いた場合は、開封せずに保管し、確認できなければそのまま返却します。

## 4-C. 郵便の受け取りを確認できていないとき

4-A を送ってから【例: 10】日たっても受け取りを確認できないときに、一度だけ送ります。

件名: 【{受付番号}】本人確認の郵便について(【屋号】)

```
{氏名} 様

【屋号】 です。{郵便発送日} にお送りした本人限定受取郵便について、まだお受け取りを確認できていません。

・郵便局からの通知が届いていましたら、通知に従ってお受け取りください。
・通知が届いていない場合や、お申し込みのご住所・お名前の表記に心当たりがある場合は、このメールへのご返信でお知らせください。
・郵便局での保管の期間を過ぎると、郵便は当店に戻ります。受け取りを確認できない場合、買取の手続きには進めません。

お取引を見送られる場合は、ご返信は不要です。あらためてお申し込みいただけます。
```

運営者向けメモ: 郵便が当店に戻ってきたら、定型文 10(本人確認の不備)で知らせます。

## 5. 到着連絡

件名: 【{受付番号}】カードが到着しました(【屋号】)

```
{氏名} 様

【屋号】 です。{到着日} にカードを受け取りました。

受け取った枚数: {枚数}枚
検品結果のご連絡: {検品期限} まで

買取額は、到着日({到着日})の相場で計算します。
```

枚数が申込と違う場合は、「受け取った枚数」の行の下に次を足します。

```
お申し込みの枚数({枚数}枚)と異なっています。開封時の写真を添付します。お心当たりをお知らせください。
```

## 6-A. 検品結果(満額)

件名: 【{受付番号}】検品結果のお知らせ(【屋号】)

```
{氏名} 様

【屋号】 です。検品が終わりました。
全点、状態 A で、買取率どおりの金額です。

確定額の合計: {確定合計} 円({到着日} の相場で計算)

{検品明細}

承諾いただける場合は、このメールに「承諾します」とご返信のうえ、
お振込先(銀行名、支店名、口座の種別、口座番号、口座名義)をお知らせください。
口座はご本人名義に限ります。承諾から3営業日以内に振り込みます。

返却をご希望のカードがある場合は、カード名をお知らせください。1枚単位で選べます。

ご返信の期限: {返信期限}
```

仮査定から金額が変わった場合は、明細の前に次を足します。

```
仮査定({仮査定合計} 円)との差は、到着日の相場で計算し直したことによるものです。
```

## 6-B. 検品結果(一部減額)

件名: 【{受付番号}】検品結果のお知らせ(【屋号】)

```
{氏名} 様

【屋号】 です。検品が終わりました。
一部のカードが、当店の基準で状態 B または C となりました。
1枚ごとの結果と理由は次のとおりです。該当箇所の写真を添付します。

確定額の合計(全点を承諾いただいた場合): {確定合計} 円({到着日} の相場で計算)

{検品明細}

カードごとに「承諾」か「返却」をお選びいただけます。
このメールへのご返信で、次のどちらかをお知らせください。

・全点を承諾する
・一部を返却する(返却するカード名をお書きください)

承諾いただくカードがある場合は、お振込先(銀行名、支店名、口座の種別、口座番号、口座名義)も
あわせてお知らせください。口座はご本人名義に限ります。
返却の送料は当店が負担します。

ご返信の期限: {返信期限}
```

{検品明細} の1行の書き方:

```
3. {カード名}({型番}) 状態 B / 基準相場 30,000円 × 93% × 【80】% = 22,320円
   理由: 裏面の右下に点状の白かけ2か所(写真 3-1)
```

## 6-C. 検品結果(全返却)

件名: 【{受付番号}】検品結果のお知らせ(【屋号】)

```
{氏名} 様

【屋号】 です。検品が終わりました。
申し訳ありませんが、全点、買取をお受けできない結果となりました。
1枚ごとの理由は次のとおりです。該当箇所の写真を添付します。

{検品明細}

カードは、受け取ったときの状態のまま返却します。
返却先がお申し込みのご住所と違う場合は、{返信期限} までにお知らせください。
ご連絡が無い場合は、お申し込みのご住所へお送りします。
```

運営者向けメモ: 禁止事項(偽造・加工の疑いなど)が理由の場合は、返却の送料の扱いが変わります
(買取ルール 6.)。その場合は「返却は着払いでお送りします」の1文を足します。
盗品の疑いがある場合の対応は、所轄の警察署に確認した手順に従います。

## 9. 期限のリマインド

### 9-A. 発送の期限(期限の2日前。発送のお願い 4-B を送った後に使う)

件名: 【{受付番号}】発送の期限のお知らせ(【屋号】)

```
{氏名} 様

【屋号】 です。発送の期限が {発送期限} となっています。

期限までに発送のご連絡が無い場合、お申し込みは取り消しとなります。
取り消しとなっても、あらためてお申し込みいただけます。
見送られる場合は、ご返信は不要です。
```

### 9-B. 承諾・返却の返信期限(期限の前日)

件名: 【{受付番号}】ご返信の期限のお知らせ(【屋号】)

```
{氏名} 様

【屋号】 です。検品結果へのご返信の期限が {返信期限} となっています。

カードごとに「承諾」か「返却」を、このメールへのご返信でお知らせください。
期限から【7】日たってもご返信が無い場合は、全点を返却します。
```

### 9-C. 期限切れによる返却

件名: 【{受付番号}】カードを返却します(【屋号】)

```
{氏名} 様

【屋号】 です。検品結果へのご返信の期限を過ぎたため、買取ルールにもとづき、全点を返却します。
【3】営業日以内に発送し、追跡番号をお知らせします。
```

## 10. 本人確認の不備

件名: 【{受付番号}】本人確認についてのお願い(【屋号】)

```
{氏名} 様

【屋号】 です。本人確認の手続きで、次の点を確認できませんでした。

{不備内容}

お手数ですが、このメールへのご返信で、あらためてお知らせください。
確認ができるまで、発送のご案内(またはお振込)は保留となります。
```

{不備内容} の選択肢:

- お送りした本人限定受取郵便が、宛先不明で当店に戻りました。本人確認書類に書かれているご住所とお名前の表記をお知らせください。
- お送りした本人限定受取郵便が、受け取られないまま当店に戻りました。お取引を続ける場合は、受け取れる時期をお知らせください。
- お振込先の口座名義が、お申し込みの氏名と一致していません。

使い分け: 郵便がまだ戻っておらず、受け取りの確認が取れていないだけのときは 4-C を使います。
郵便が戻ってきたとき、口座名義が合わないときに、この定型文を使います。
郵便を送り直すときの費用の扱いは【運営者が決める】。

## 11. 当店の連絡が遅れるとき

件名: 【{受付番号}】ご連絡が遅れます(【屋号】)

```
{氏名} 様

【屋号】 です。{検品期限} までにお知らせする予定でしたが、ご連絡が遅れます。申し訳ありません。
新しい期限: {新しい期限}

お待ちいただけない場合は、このメールへのご返信でお知らせください。カードを返却します(送料は当店が負担します)。
```

## よくある問い合わせへの返し(短文)

| 問い合わせ | 返し |
|---|---|
| 金額を上げてほしい | 買取額は「基準相場 × 買取率」で決めており、個別のご相談はお受けしていません。計算の内訳は明細のとおりです。 |
| 対象外のカードも見てほしい | 買取は対象リストのカードに限っています。リストは随時更新しますので、追加をお待ちください。 |
