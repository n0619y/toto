# 定型文

- { } は差し込み項目。送る前に、{ } が残っていないか確かめます。
- 【 】は運営者が最初に一度だけ埋める箇所(期限の日数、URL など)。数字は例です。
- 件名の先頭に受付番号を付けます。文面は変えずに使います。
- 署名は共通です。

```
toto mint
古物商許可: 【◯◯県公安委員会 第◯◯◯◯◯◯◯◯◯◯◯◯号】
【◯◯県◯◯市】 / 【メールアドレス】
買取ルール: 【URL】
```

## 差し込み項目の一覧

| 項目 | 内容 |
|---|---|
| {氏名} | 申込者の氏名 |
| {受付番号} | 例: K261201-01 |
| {枚数} | 枚数 |
| {仮査定合計} | 仮査定の合計額 |
| {仮査定明細} | 1枚ごとの明細(カード名 / 基準相場 / 買取率 / 仮査定額) |
| {相場確認日} | 仮査定に使った相場の日付 |
| {発送期限} | 発送の期限の日付 |
| {到着日} | 当店に到着した日 |
| {検品期限} | 検品結果を連絡する期限の日付 |
| {検品明細} | 1枚ごとの明細(カード名 / 状態 / 到着日の基準相場 / 確定額 / 理由) |
| {確定合計} | 確定額の合計 |
| {返信期限} | 承諾・返却の返信期限の日付 |
| {振込日} | 振込を行った日 |
| {振込額} | 振り込んだ金額 |
| {追跡番号} | 返却時の追跡番号 |
| {対象外理由} | 対象外・お断りの理由 |
| {不備内容} | 本人確認の不備の内容 |
| {カード名} / {型番} | 明細の1行に入れるカード名と型番 |
| {口座下3桁} | 振込先の口座番号の下3桁 |
| {新しい期限} | 当店の連絡が遅れるときの、新しい期限の日付 |

## 1. 自動返信(フォームの確認メッセージ)

```
お申し込みありがとうございます。toto mint です。

内容を確認し、【2】営業日以内に、仮査定の結果をメールでお知らせします。
ご入力のメールアドレスに、申込内容の控えをお送りしました。

・仮査定は参考価格です。買取額は、到着日の相場で計算し直して確定します。
・カードの発送は、仮査定のご連絡をお待ちください。

控えのメールが届かない場合は、迷惑メールのフォルダをご確認ください。
```

## 2. 仮査定の連絡

件名: 【{受付番号}】仮査定の結果(toto mint)

```
{氏名} 様

toto mint です。お申し込みありがとうございます。
仮査定の結果をお知らせします。

受付番号: {受付番号}
仮査定の合計: {仮査定合計} 円({枚数}枚、{相場確認日} 時点の相場で計算)

{仮査定明細}

・この金額は参考価格です。買取額は、到着日の相場で計算し直して確定します。
・状態は写真から判断しています。実物の検品で区分が変わることがあります。
・確定額にご納得いただけない場合は、1枚単位で返却を選べます。

お進みになる場合は、このメールに「発送します」とご返信ください。
発送の方法をご案内します。ご返信の期限は {発送期限} です。
```

## 3. 対象外のお断り

件名: 【{受付番号}】お申し込みについて(toto mint)

```
{氏名} 様

toto mint です。お申し込みありがとうございます。
申し訳ありませんが、今回のお申し込みは買取をお受けできません。

理由: {対象外理由}

対象カードと最低ロットは、買取ルールのページでご確認いただけます。
対象リストは随時更新しています。条件が合うときに、またお申し込みください。
```

{対象外理由} の選択肢(このどれかを入れる):

- お申し込みのカードが対象リストにありません。
- 対象カードの合計が、最低ロット(【例: 合計5万円以上、または10枚以上】)に届いていません。
- 写真から、当店の状態基準で C にあたると判断しました。
- 基準相場を出せるだけの成約件数がありません。
- 現在、新規の受付を停止しています。
- 買取ルールの「未成年の方」「禁止事項」により、お受けできません。

一部だけ対象外の場合は、定型文 2 の明細に「対象外(理由)」と書き、この定型文は使いません。

## 4. 発送依頼

件名: 【{受付番号}】発送のご案内(toto mint)

```
{氏名} 様

toto mint です。ご返信ありがとうございます。
発送の前に、次の2点をこのメールへのご返信でお知らせください。

1. ご住所(郵便番号から)、生年月日、ご職業
2. 本人確認: 【所轄の警察署に確認した方法に合わせた案内文】

確認ができましたら、発送先をお知らせします。

発送の方法:
・【配送会社・サービス名】の着払いでお送りください(送料は当店が負担します)。
・カードは1枚ずつスリーブとローダーに入れ、水ぬれ防止の袋に入れてください。
・箱の中に、受付番号 {受付番号} を書いたメモを入れてください。
・発送後、追跡番号をこのメールへのご返信でお知らせください。

発送の期限: {発送期限}
期限までに発送のご連絡が無い場合、お申し込みは取り消しとなります。
```

運営者向けメモ: 発送先の住所は、本人確認の手順が済んでから別のメールで知らせます。
最初からこのメールに書く運用にする場合は、上の「確認ができましたら〜」の行を発送先に置き換えます。

## 5. 到着連絡

件名: 【{受付番号}】カードが到着しました(toto mint)

```
{氏名} 様

```

## 6-A. 検品結果(満額)

件名: 【{受付番号}】検品結果のお知らせ(toto mint)

```
{氏名} 様

toto mint です。検品が終わりました。
全点、状態 A で、買取率どおりの金額です。

確定額の合計: {確定合計} 円({到着日} の相場で計算)

{検品明細}

承諾いただける場合は、このメールに「承諾します」とご返信のうえ、
お振込先(銀行名、支店名、口座の種別、口座番号、口座名義)をお知らせください。
口座はご本人名義に限ります。承諾から【2】営業日以内に振り込みます。

```

仮査定から金額が変わった場合は、明細の前に次を足します。

```
仮査定({仮査定合計} 円)との差は、到着日の相場で計算し直したことによるものです。
```

## 6-B. 検品結果(一部減額)

件名: 【{受付番号}】検品結果のお知らせ(toto mint)

```
{氏名} 様

toto mint です。検品が終わりました。
一部のカードが、当店の基準で状態 B または C となりました。
1枚ごとの結果と理由は次のとおりです。該当箇所の写真を添付します。

確定額の合計(全点を承諾いただいた場合): {確定合計} 円({到着日} の相場で計算)

{検品明細}

カードごとに「承諾」か「返却」をお選びいただけます。
このメールへのご返信で、次のどちらかをお知らせください。

・全点を承諾する
・一部を返却する(返却するカード名をお書きください)

承諾いただくカードがある場合は、お振込先(銀行名、支店名、口座の種別、口座番号、口座名義)も
あわせてお知らせください。口座はご本人名義に限ります。
返却の送料は当店が負担します。

ご返信の期限: {返信期限}
```

{検品明細} の1行の書き方:

```
3. {カード名}({型番}) 状態 B / 基準相場 10,000円 × 93% × 80% = 7,440円
   理由: 裏面の右下に点状の白かけ2か所(写真 3-1)
```

## 6-C. 検品結果(全返却)

件名: 【{受付番号}】検品結果のお知らせ(toto mint)

```
{氏名} 様

toto mint です。検品が終わりました。
申し訳ありませんが、全点、買取をお受けできない結果となりました。
1枚ごとの理由は次のとおりです。該当箇所の写真を添付します。

{検品明細}

カードは、受け取ったときの状態のまま返却します。
返却先がお申し込みのご住所と違う場合は、{返信期限} までにお知らせください。
ご連絡が無い場合は、お申し込みのご住所へお送りします。
```

運営者向けメモ: 禁止事項(偽造・加工の疑いなど)が理由の場合は、返却の送料の扱いが変わります
(買取ルール 6.)。その場合は「返却は着払いでお送りします」の1文を足します。
盗品の疑いがある場合の対応は、所轄の警察署に確認した手順に従います。

## 10. 本人確認の不備

件名: 【{受付番号}】本人確認についてのお願い(toto mint)

```
{氏名} 様

toto mint です。本人確認の手続きで、次の点を確認できませんでした。

{不備内容}

お手数ですが、このメールへのご返信で、あらためてお知らせください。
確認ができるまで、発送先のご案内(またはお振込)は保留となります。
```

{不備内容} の選択肢:

- お申し込みの氏名と、本人確認の氏名が一致していません。
- お申し込みのご住所と、本人確認のご住所が一致していません。
- 書類の文字が読み取れません。
- 書類の有効期限が切れています。
- お振込先の口座名義が、お申し込みの氏名と一致していません。

## よくある問い合わせへの返し(短文)

| 問い合わせ | 返し |
|---|---|
| 金額を上げてほしい | 買取額は「基準相場 × 買取率」で決めており、個別のご相談はお受けしていません。計算の内訳は明細のとおりです。 |
| 対象外のカードも見てほしい | 買取は対象リストのカードに限っています。リストは随時更新しますので、追加をお待ちください。 |
| 鑑定で高い評価が出そうか | 当店の状態区分は当店の基準によるもので、鑑定の結果を予測・保証するものではありません。 |
| X の DM で進めたい | 個人情報を扱うため、お取引のご連絡はメールでお願いしています。 |
| 先に振り込んでほしい | お振込は、検品と承諾の後に行っています。 |
