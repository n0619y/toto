# PSA鑑定 収支管理シート よくある質問(FAQ)

バージョン v1.0(2026-11-27)

個別のサポートは行っていないため、困ったときはまずこの FAQ と、ファイル内の「使い方」シートをご覧ください。
このファイルは PSA(Professional Sports Authenticator)社とは関係のない非公式のツールです。

## 開く・取り込む

### Q1. Excel で開いたら、数字が出ず空欄に見えます。

画面上部に「保護ビュー」の黄色い帯が出ていたら、「編集を有効にする」を押してください。押すまで数式の結果は表示されません。
このファイルには計算済みの値を入れておらず、開いたアプリがその場で計算する作りです。そのため、販売サイトやスマートフォンのプレビュー表示、メールの添付プレビューなどでは、灰色のセルが空に見えることがあります。Excel か Googleスプレッドシートで開いて確かめてください。

### Q2. Googleスプレッドシートで使うには、どうすればいいですか。

1. Googleスプレッドシートで空のファイルを開く
2. 「ファイル」→「インポート」→「アップロード」で `psa-shushi-kanri.xlsx` を選ぶ
3. 「新しいスプレッドシートを作成する」を選んで取り込む

取り込んだあとのファイルは、元の xlsx とは別物として保存されます。元の xlsx(または購入時の zip)は消さずに取っておいてください(Q9 を参照)。
なお、Excel・Googleスプレッドシートでの動作確認の状況は、販売ページの「対応環境」をご覧ください。

### Q3. スマートフォンや、Excel・Googleスプレッドシート以外のアプリでも使えますか。

パソコンの Microsoft Excel と Googleスプレッドシートを対象にしています。スマートフォンのアプリでの操作は想定していません(表が横に長く、入力しづらいためです)。
Numbers など他の表計算アプリは対象外で、動くかどうかは確認していません。マクロ(VBA)やアドインは使っていません。

## 入力する

### Q4. 最初に何をすればいいですか。

1. 「設定」シートの黄色いセルを、ご自身の実際の為替・鑑定料・送料・税率などに書き換える(初期値は一例です)
2. 「在庫台帳」のサンプル5行を消す(黄色いセルだけを選んで Delete。灰色のセルは消さない)
3. 「在庫台帳」に、カード1枚を1行で記録していく
4. 「注文別集計」の見本の注文番号(SAMPLE-001)を、自分の注文番号に書き換える

黄色いセルが入力欄、灰色のセルは数式です。灰色のセルには入力しないでください。

### Q5. 為替や鑑定料を変えたら、過去の行の金額まで変わりました。なぜですか。

設定は1組だけで、在庫台帳のすべての行が「設定」シートの同じ値を見て鑑定費用を計算しているためです。設定を変えると、過去の行を含む全行が新しい値で計算し直されます。
過去ぶんの金額を固定したいときは、その行の「鑑定費用」のセル(灰色)に、実際にかかった金額を直接入力してください。その行だけ数式が消えて固定の数字になりますが、原価合計や利益など他の計算はそのまま動きます。
注文ごと・サービスレベルごとに料金を持ち分ける機能はありません。料金が違う注文は、同じ方法で行ごとに実額を上書きしてください。

### Q6. 鑑定済みのカードを買った場合や、まだ鑑定に出していないカードの鑑定費用はどうなりますか。

- 状態が「在庫」で、グレードが「未鑑定」(または空欄)の行は、まだ鑑定に出していないとみなして鑑定費用は 0 円です。
- それ以外の行には、1枚あたりの鑑定費用が自動で入ります。
- 鑑定済みの状態で仕入れたカードは、グレードを入れると鑑定費用が入ってしまうので、「鑑定費用」のセルに 0 を直接入力してください。

### Q7. 行を並べ替えたり、フィルタをかけたりしても大丈夫ですか。

在庫台帳は、並べ替え・フィルタ・行の削除をしても計算が壊れないように、数式が自分の行だけを見る作りにしています。見出し行のフィルタのボタンから並べ替えてください。
避けてほしいのは次の操作です。

- 黄色いセルの「切り取り→貼り付け」やドラッグでの移動(数式の参照先がずれます。移すときは「コピー→貼り付け」のあと、元のセルを Delete)
- 灰色のセルへの入力
- シート名の変更、列の挿入・削除

### Q8. 500行を超えたらどうすればいいですか。注文別集計の30行を超えたら?

在庫台帳は、数式が入っている最後の行(501行目)全体をコピーして下の行に貼り付け、黄色いセルを Delete してから使ってください。集計は列全体を見ているので、足した行もそのまま集計に入ります。
注文別集計は30注文までで、行を足すことはできません。このシートは在庫台帳を集計して表示しているだけなので、見終わった注文番号を別の注文番号に書き換えて使ってください(書き換えても在庫台帳の記録は消えません)。

### Q9. 数式を消してしまいました。#DIV/0! や #VALUE! が出ます。

- エラーが出たら、まず「設定」シートの「設定チェック」を見てください。「要確認」のときは、9項目に空欄や文字が入っていないか、1箱の枚数が1以上かを確認します。
- 在庫台帳の数式を消した場合は、同じ列の上下の行のセルをコピーして貼り付けると戻ります。
- それでも直らないとき、どこを消したか分からないときは、配布された元のファイル(購入時の zip に入っている xlsx)を開き直し、入力した内容(黄色いセル)を「コピー→貼り付け」で移してください。

購入時の zip は、消さずに取っておくことをおすすめします。販売サイトから再ダウンロードできるかどうかは、販売サイトの仕様によります。

### Q10. 月次集計に、売ったはずのカードが入りません。

月次集計に入るのは、状態が「売却済」で、売却日が「集計する年」に入っている行です。次を確認してください。

- 月次集計シートの「集計する年(西暦)」が合っているか
- 状態が「売却済」になっているか
- 売却日が 2026/3/15 の形の日付で入っているか(「3月15日ごろ」のような文字は集計されません)

売却日や売却額の入れ忘れは、月次集計シートの「チェック」欄に件数が出ます。

### Q11. 販売手数料や送料は、どこに入れればいいですか。

フリマなどの販売手数料は、「設定」シートの「販売手数料率」に % で入れます(10% なら 10)。全行に同じ率がかかります。店頭買取など手数料が無い場合は 0 のままにします。
売るときの送料の欄はありません。含めたい場合は、売却額から送料を引いた金額を売却額に入れるなど、ご自身でルールを決めてください。
鑑定に出すときの送料・関税は「1箱の枚数」で均等に割ります。箱ごとに枚数が違っても、その差は反映しません(固定したい行は Q5 の方法で実額を上書きしてください)。

### Q12. シートが保護されていて編集できません。

「設定」「注文別集計」「月次集計」「シミュレーター」は、数式を誤って消さないよう保護しています(パスワードはありません)。黄色いセルはそのまま入力できます。
保護を外したい場合、Excel では「校閲」→「シート保護の解除」で外せます。外したあとに数式を壊した場合は、Q9 の方法で元のファイルに戻してください。

## 使える範囲

### Q13. PSA 以外の鑑定会社でも使えますか。

費用の項目名(鑑定料・往路送料・復路送料・関税など)をご自身で読み替えれば、費用と利益の計算には使えます。ただし次の点にご注意ください。

- グレードのプルダウンは「未鑑定 / PSA10 / PSA9 / PSA8以下」の4つで固定です。他社の等級(9.5 など)はそのままでは選べないので、4つのどれかに読み替えて入れることになります。
- ドル建ての費用を円に直す作りです(通貨は円とドルの1組だけ)。
- 確認しているのは、このシートの計算式が式どおりに計算されることだけです。他社の料金体系や手続きに合うかどうかは確認していません。

### Q14. シミュレーターの結果どおりに利益が出ますか。相場は自動で入りますか。

いいえ。シミュレーターは、ご自身が入れた売値と確率から平均(期待値)を計算するだけで、将来の相場や鑑定結果を予測するものではありません。利益が出ることを保証するものでもありません。
相場や PSA の注文状況を自動で取得する機能はなく、すべて手入力です。

### Q15. 税金や関税の計算は、これで合っていますか。確定申告に使えますか。

このシートは収支の記録と試算のための道具で、税額を計算するものではありません。「設定」シートの税率・関税の初期値は一例で、実際の税額や制度を示すものではありません。消費税・所得税の計算機能もありません。
税務(確定申告・所得の区分・消費税など)と、関税・輸入時の税の扱いは、取引の内容や時期によって変わります。必ずご自身で、税理士・税務署・税関などの専門家や公的機関に確認してください。
