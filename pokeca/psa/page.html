PSA入力アシスト

PSAの申込画面で、鑑定プランの選択から、カードの検索・選択・枚数入力・Saveまでを順番に自動で行います。Proceed to Checkout と Place Order、規約のチェックは押しません。

初回だけ

ブックマークに登録する(Android の Chrome)

  1. 下のボタンでコードをコピーする。
  2. Chrome で適当なページを開き、メニュー(⋮)の ☆ でブックマークに追加する。
  3. メニュー → ブックマーク → いま追加したものの「編集」を開く。
  4. 名前を psa に、URL を消してコピーしたコードを貼り付けて保存する。

毎回 1

入力リストを作る

1行に1種類。「セット記号 カード番号 x枚数」の順で書きます。記号と番号はカード左下に印刷されています。枚数が1なら省略できます。

上の3行は記入例です。消して自分のカードを書いてください。

毎回 2

PSAの画面で実行する

  1. PSAで Start Submission → Grade with PSA → New Submission → Classic Submission と進み、「Select Item Type」の画面を出す。
  2. アドレスバーをタップして psa と打ち、候補に出る ☆ 付きの「psa」をタップする。
  3. 出てきた入力欄にリストを貼り付けて OK を押す。Trading Cards → Grading → 鑑定プランの順に自動で進み、カードの入力が始まる。
  4. リストでプランを「PSAの画面で選ぶ」にした場合は、プランの一覧が番号付きで出るので、番号を入れて選ぶ。
  5. 終わると「追加 ◯件 / 飛ばした ◯件」と表示される。飛ばしたカードは手で入力する。
  6. 一覧と枚数を確認してから、自分で Proceed to Checkout に進む。

候補が1件に絞れないカード(同じ番号で通常版とミラー版があるなど)は、間違いを避けるため選ばずに飛ばします。

実際のPSAの画面ではまだ試していません。うまく動かない場合は、表示されたメッセージか画面のスクリーンショットを送ってください。
